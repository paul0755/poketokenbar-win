# PokeTokenBar 0.6.0

키운 아이를 친구와 **교환**하고, 같은 결투를 두 화면에서 **실시간으로** 봅니다.
**내 방(미니룸)** 을 꾸며 아이들을 두고, 창을 끌어 **크게** 볼 수 있습니다.

0.5.0 다음 버전입니다.

---

## 새로 생긴 것

### 🏠 미니룸 — "방" 탭

- 내 방을 꾸미고, 박스에서 고른 아이들(최대 5마리)을 둡니다. 아이들은 방 안을 걸어 다닙니다
- **배경** — 오두막(기본) · 바닷가 · 밤하늘 · 연구소(🍬4)
- **가구** — 창문(기본) · 스탠드 램프 · 둥근 러그 · 몬스터볼 쿠션 · 나무열매 화분(🍬2) · 기술머신 책장(🍬3).
  산 가구는 놓거나 치울 수 있습니다
- **키운 기록이 장식이 됩니다** — 도감 액자(도감 수), 결투 배지 진열장(1·10·30·100승마다 하나씩 빛남),
  졸업 트로피(마지막 졸업생 이름). 사지 않아도 저절로 생깁니다
- 진화 단계마다 덩치가 다르고, 이로치는 반짝입니다. 쿠션이 있으면 가장 작은 아이가 올라앉아 쉽니다.
  누르면 이름표가 뜹니다

### 🔁 교환 · 교환 진화

- 결투 탭의 **교환**에서 아이 하나를 **교환 코드**(`PTBT-…`)로 보냅니다. 내 박스에서 빠지고, 친구가 코드를
  붙여 넣으면 그쪽 박스에 같은 모습·레벨로 들어갑니다. 같은 코드는 한 번만 받을 수 있습니다
- 윤겔라·근육몬·데구리·고우스트처럼 **원작에서 교환으로 진화하는 아이는 받는 순간 진화합니다**
- 실수로 보냈으면 그 코드를 내가 다시 받으면 돌아옵니다
- 서버를 쓰지 않습니다. 코드는 사람이 복사해서 보냅니다

### ⚡ 실시간 배틀 — 같은 결투를 동시에

- 결투 탭에서 방을 만들면 6자리 코드가 나옵니다. 친구가 그 코드로 들어와 둘 다 **준비**를 누르면
  카운트다운 뒤 **두 화면에서 같은 결투가 같은 시각에** 시작됩니다(Lv.50, 보상 없음)
- 방에 들어간 뒤에도 내보낼 포켓몬을 바꿀 수 있습니다. 바꾸면 둘 다 다시 준비합니다
- 결투 계산은 각자의 앱이 합니다. 서버는 서로의 팀 코드와 시작 시각만 전해 주고, 아무것도 저장하지 않습니다
- **설정 › 온라인 기능을 켜야** 쓸 수 있습니다. 기본은 꺼짐입니다(아래 "보내는 것")

### 🪨 변하지않는돌

- 상점에서 사서(🍬3) **박스 › 상세 › 지닌 물건**에서 지니게 합니다
- 원작처럼 **모습은 그대로, 레벨·기술은 계속 오릅니다.** 빼면 돌은 가방으로 돌아오고 그동안 쌓인 만큼 바로 진화합니다
- 다른 종으로 바뀌는 진화만 막습니다(2단 라인의 1차→최종, 마스터, 알 부화는 막지 않음)
- 교환으로 보내면 돌도 함께 가고, 지닌 채 받으면 교환 진화를 하지 않습니다

### ↔️ 창 크기 조절

- 메인 창 테두리를 끌어 크기를 바꿉니다(최소 400×460). 바꾼 크기는 기억합니다
- 넓히면 홈은 두 단, 상점·박스·도감은 여러 칸으로 펼쳐지고, 방은 창 높이에 맞춰 커집니다

## 바뀐 것 · 고친 것

- **몬스터볼 던지기** — 직선으로 뻗던 것을 포물선으로 바꿨습니다. 빗나가면 작업표시줄 위 바닥에
  떨어져 통통 튀다 사라집니다
- **소스에서 설치할 때** `Electron failed to install correctly (node_modules\electron\index.js)` 로
  멈추던 것 — npm 이 Electron 의 설치 스크립트를 막으면 생겼습니다. 이제 `npm install` 뒤와
  `npm start` 앞에서 저절로 확인해 받습니다. 그래도 안 되면 `npm run fix-electron`
- 진행 초기화를 하면 미니룸과 변하지않는돌도 함께 비웁니다(사탕으로 산 것이라)

## 이 앱이 보내는 것

기본 설정에서는 **바뀐 것이 없습니다** — 보내는 요청은 처음 보는 포켓몬의 스프라이트를 받는 것
하나뿐입니다(PokeAPI/sprites, 디스크에 캐시). 교환과 친선 배틀도 네트워크를 쓰지 않습니다.

**설정 › 온라인 기능을 켰을 때만** 실시간 배틀 중계 서버(Cloudflare Workers)에 방 코드, 내 팀 코드
(포켓몬 한 마리의 종·개체값·기술 등), 트레이너 이름을 보냅니다. **토큰 사용 기록·로그·파일 경로·세이브는
보내지 않습니다.**
