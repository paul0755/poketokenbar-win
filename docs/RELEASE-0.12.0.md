# PokeTokenBar 0.12.0

**길드끼리 겨루는 🏆 길드 랭킹**과, 한 주에 하나뿐인 **마스터볼**이 생겼습니다.
코인으로 사탕을 살 수 있고, 볼 그림을 새로 그렸습니다.

0.11.1 다음 버전입니다.

---

## 새로 생긴 것

### 📋 길드 목록 — 방 탭의 세 번째 탭

- 방 탭 위가 **🏠 내 방 · 🏰 길드 · 📋 길드 목록** 셋이 됐습니다. 길드 목록은 이제 따로 된 탭에 있습니다
- 길드가 없으면 목록에서 **들어가기** 한 번으로 들어가고, 바로 🏰 길드 탭으로 넘어갑니다.
  트레이너 이름은 🏰 길드 탭의 칸을 쓰고, 비었으면 친선 배틀 이름을 씁니다
- 길드에 들어가 있으면 내 길드에 "내 길드"가 달리고, 다른 길드에는 지금 길드를 나간 뒤 들어갈 수 있다고 알려 줍니다
- 0.11.1 의 **🔎 다른 길드 보기** 단추는 이 탭으로 옮기면서 없앴습니다

### 🏆 길드 랭킹 — 📋 길드 목록 탭의 [목록 | 🏆 랭킹]

- 목록에 올린 길드끼리 **이번 주 · 지난주** 순위를 봅니다. 지난주 1위에는 👑
- 기준 셋
  - **합계** — 순위를 공개한 길드원의 토큰 합계
  - **1인당** — 합계 ÷ 그 주에 쓴 사람 수. 쓴 사람이 3명 이상인 길드만
  - **🎯 목표** — 길드마다 자기 최근 4주 평균으로 정한 🥇 목표에 얼마나 다가갔나. 작은 길드도 겨룰 수 있습니다
- 30위까지 보이고, 내 길드는 노란 테두리. 30위 밖이면 맨 아래에 따로 보입니다
- 내 길드가 랭킹에 없으면 왜 없는지(목록에 안 올림 · 기록 없음 · 3명이 안 됨) 알려 줍니다
- 길드원이 방을 올릴 때 10분에 한 번까지 바뀝니다. **코인 보상은 없습니다** — 보여 주기만 합니다

### 🟣 마스터볼 — 사탕 상점

- 🍬40, **한 주(월요일부터)에 1개만** 삽니다. 던지면 **반드시 잡힙니다 — 전설도**
- 다른 볼이 떨어져도 저절로 마스터볼로 바뀌지 않습니다. 하나뿐이라 아무 포켓몬에게나 모르고 던지지 않게,
  야생에서 볼을 눌러 직접 고릅니다(마스터볼밖에 안 남았을 때만 저절로)
- 상점에서 사면 단추가 "이번 주 ✓"로 바뀝니다. 볼 칸에는 가진 수가 보입니다

### 🍬 코인으로 사탕 사기 — 🛒 길드 몰의 지갑 칸

- **사탕 사기** — 🍬1 에 🪙20, 하루 5개까지
- 사탕 → 코인(🍬1 → 🪙5)보다 훨씬 비싸서, 오가며 불릴 수는 없습니다

## 바뀐 것

- **볼 그림을 새로 그렸습니다** — 몬스터볼(빨강) · 슈퍼볼(파랑 + 빨간 날개) · 하이퍼볼(검정 + 노란 H) ·
  마스터볼(보라 + 분홍 혹 + 흰 M). 던지는 창과 상점 아이콘이 같은 그림을 씁니다(🔵🟡 이모지 대신)
- 길드 목록에 올리면 **🏆 랭킹에 길드 합계가 보인다**는 걸 길드 만들기 · 📋 길드 목록에 올리기 문구에 적었습니다

---

## 이 앱이 보내는 것 — 조금 늘었음

- **목록에 올린 길드는 최근 두 주의 길드 합계 · 쓴 사람 수 · 목표 진행이 길드 목록 서버에 갑니다**(랭킹용,
  앱을 쓰는 누구에게나 보임). 길드원 한 사람 한 사람의 숫자는 지금처럼 길드 안에서만 보입니다.
  합계는 원래도 길드 서버에 있던 숫자를 길드가 더해서 보내는 것이고, 앱이 새로 보내는 건 없습니다
- 코인 → 사탕은 지갑에 사는 개수와 날짜를 보냅니다(환전과 같은 꼴)
