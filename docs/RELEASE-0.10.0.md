# PokeTokenBar 0.10.0

길드가 **함께 목표를 이루고, 함께 홀을 꾸밉니다.** 이번 주 길드 합계로 🥉 🥈 🥇 목표를 이루면 길드원 모두
코인을 받고, 모은 코인으로 길드 홀에 장식을 들입니다. 길드에 들어간 뒤에도 이름을 바꿀 수 있습니다.

0.9.0 다음 버전입니다.

---

## 새로 생긴 것

### 🎯 길드 공동 목표 — 길드 홀 위 막대

- 이번 주 길드 합계 토큰으로 목표가 셋: **🥉 · 🥈 · 🥇**
- 목표는 **그 길드의 최근 4주 평균**으로 정해집니다(×0.8 · ×1.0 · ×1.25) — "평소만큼 쓰면 🥈".
  기록이 없는 새 길드는 공개한 길드원 수 × 2억으로 시작합니다. 한 주 안에는 목표가 바뀌지 않습니다
- 주가 확정되면(다음 주 시작 36시간 뒤) 이룬 만큼 **🥉 🪙10 · 🥈 🪙20 · 🥇 🪙35** 를
  **그 주에 쓴 길드원 모두**에게 줍니다(그 주가 시작하기 전부터 길드원이었던 사람). 1위 · 칭호 보상과는 따로입니다
- 합계는 순위를 공개한 사람만 셉니다(공개를 끈 사람은 숫자가 서버에 오지 않습니다)
- 막대에 남은 양과 보상이 보이고, 지난주 목표를 이뤘으면 길드 탭을 열 때 한 번 알려 줍니다

### 🏗️ 길드 홀 꾸미기 — 길드원이 함께 모금

| 장식 | 모금액 | |
|---|---|---|
| 🌷 꽃 화단 | 🪙200 | 입구 양옆 꽃밭 |
| 🚩 길드 깃발 추가 | 🪙300 | 벽 깃발 2개 → 4개 |
| 🕯️ 샹들리에 | 🪙500 | 천장에서 반짝, 밤엔 홀이 밝아진다 |
| 📺 전광판 게시판 | 🪙600 | 게시판이 이번 주 목표 진행 화면으로 |
| ⛲ 황금 분수 | 🪙800 | 분수가 금빛, 물줄기가 더 높다 |
| 🏆 우승 트로피 진열장 | 🪙1000 | 길드가 목표 🥇를 이룬 주만큼 트로피 |
| 🟥 레드카펫 금테 | 🪙1200 | 융단 테두리가 금실로 |
| 🗿 길드 마스코트 석상 | 🪙1500 | 지난주 1위의 대표 포켓몬을 돌로 깎는다 |
| 🏰 홀 배경: 성 | 🪙2000 | 성벽 · 스테인드글라스 · 대리석 |
| ☁️ 홀 배경: 하늘 신전 | 🪙3000 | 구름 위 흰 기둥 · 금줄 대리석 |

- 길드 탭 아래 **🏗️ 홀 꾸미기** 에서 장식마다 **+🪙10 / +🪙50 / 직접** 넣습니다. 다 모이면 바로 홀에 놓입니다
- 누가 얼마 보탰는지 장식마다 남습니다. **넣은 코인은 돌려받지 않습니다**(길드를 나가도 길드에 남습니다)
- 남은 금액이나 가진 코인보다 많이 적으면 넣을 수 있는 만큼만 들어갑니다. 🪙50 이상은 한 번 더 눌러야 합니다
- 홀 배경은 처음 다 모인 것을 바로 바르고, 그다음부터는 **길드장이** 고릅니다

### ✏️ 길드에서 내 이름 바꾸기

- 길드 탭 아래 **✏️ 내 이름** — 길드에 들어간 뒤에도 트레이너 이름을 바꿉니다. 길드원 목록 · 순위 · 홀 이름표에 바로 반영됩니다
- 지난 주들의 기록 · 몰에 올려 둔 매물 · 이미 만든 친선 코드에는 옛 이름이 남습니다

## 바뀐 것

- **길드 코인 보상은 "확인된 지갑"으로만 갑니다** — 지금까지는 길드 방 사진에 적힌 지갑 번호로 보상을 넣어서,
  부계정이 자기 보상을 본계정 지갑으로 몰 수 있었습니다. 이제 앱이 지갑 열쇠로 그 지갑이 정말 내 것인지 한 번
  확인하고, 한 길드에서 지갑 하나는 한 사람에게만 묶입니다
- 길드 탭을 열면 **지갑이 없을 때 앱이 만듭니다**(상점 탭을 한 번도 안 연 길드원도 보상을 받게)
- 확인 전인 사람의 보상은 버리지 않고 **14일 동안 기다렸다가** 확인되면 넣습니다. 0.9.0 이하를 쓰는 길드원은
  0.10.0 으로 올리면 그동안 쌓인 보상을 받습니다

## 이 앱이 보내는 것 — 바뀐 것 있음

기본 설정(온라인 기능 꺼짐)에서는 **바뀐 것이 없습니다.**

**온라인 기능을 켜고 길드에 들어가 있을 때** 같은 중계 서버(Cloudflare Workers)에 다음이 더해집니다.

| 보내는 것 | 언제 |
|---|---|
| 지갑 열쇠(내 지갑인지 확인용 — 저장하지 않음) | 길드에서 내 지갑이 아직 확인되지 않았을 때, 방에 코인 꾸미기를 놓았을 때 |
| 홀 모금에 넣은 장식과 코인 | 모금할 때 |

토큰 사용 기록(로그), 파일 경로, 세이브는 보내지 않습니다.

## 알려진 한계

- **결투는 0.8.0 · 0.9.0 과 그대로 됩니다** — 종 · 기술 데이터와 결투 규칙이 바뀌지 않았습니다
- **0.9.0 이하로 길드를 보면** 공동 목표 막대 · 홀 꾸미기 · 홀 장식이 보이지 않습니다. 길드 보상도 0.10.0 으로
  올려 지갑이 확인될 때까지 쌓여 있습니다(14일까지)
- 새로 만든 길드의 첫 주 목표는 그 주를 처음 셀 때의 인원으로 정해집니다 — 월요일에 혼자 만들면 그 주 목표가
  작습니다. 둘째 주부터는 기록 평균으로 정해집니다
- 사용량은 앱이 보내는 값이라 조작을 완전히 막을 수는 없습니다 — 그래서 보상을 작게 두고, 낯선 길드원은 길드장이
  내보낼 수 있습니다
