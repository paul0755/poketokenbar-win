# PokeTokenBar 0.11.0

**길드 코드를 몰라도 길드에 들어갑니다.** 길드장이 목록에 올린 길드가 길드 탭에 뜨고, 골라서 바로 들어갑니다.

0.10.0 다음 버전입니다.

---

## 새로 생긴 것

### 🔎 길드 찾기 — 길드가 없을 때 맨 위

- 길드장이 목록에 올린 길드가 뜹니다. 줄마다 **이름 · 인원(👥 4/30) · 한 줄 소개 · 이번 주 활동한 인원 · 길드장 이름 ·
  홀 장식 수 · 마지막으로 움직인 때**
- 자리가 남은 길드 먼저, 그 안에서는 이번 주 활동한 사람이 많은 순입니다. 꽉 찬 길드는 **꽉 참**으로 눌리지 않습니다
- 이름 · 소개 · 길드장 이름으로 찾습니다
- **들어가기** 한 번이면 코드 없이 들어갑니다(위의 트레이너 이름으로)
- 2주 동안 아무도 방을 올리지 않은 길드는 목록에서 감춰집니다
- 코드로 들어가기도 그대로 됩니다

### 📋 길드 목록에 올리기 — 길드장

- 길드를 만들 때 **길드 목록에 올리기**가 기본으로 켜져 있습니다
- 길드 화면 아래에서 길드장이 **올리기 · 내리기**와 **한 줄 소개(60자)** 를 바꿉니다
- 내리면 코드를 아는 사람만 들어옵니다. 목록으로 들어온 낯선 길드원은 길드장이 내보낼 수 있습니다
- **이미 있는 길드는 길드장이 켤 때까지 목록에 오르지 않습니다** — 지금까지 코드를 아는 사람끼리 쓰던 길드라서

## 이 앱이 보내는 것 — 바뀐 것 있음

기본 설정(온라인 기능 꺼짐)에서는 **바뀐 것이 없습니다.**

**온라인 기능을 켰을 때** 같은 중계 서버(Cloudflare Workers)에 다음이 더해집니다.

| 보내는 것 · 보이는 것 | 언제 |
|---|---|
| 길드 목록 불러오기(받기만) | 길드가 없을 때 길드 탭을 열면 |
| 길드 이름 · 한 줄 소개 · 코드 · 인원 · 길드장 트레이너 이름 · 이번 주 활동한 인원 · 홀 장식 수가 **앱을 쓰는 누구에게나** 보임 | 길드장이 목록에 올렸을 때만 |

길드원의 방 사진 · 토큰 합계는 목록에 오르지 않습니다(들어가야 보입니다). 토큰 사용 기록(로그), 파일 경로, 세이브는 보내지 않습니다.
