길드 홀이 풍성해졌습니다. **🚩 길드 마크**를 고르고, 새 장식 다섯과 홀 배경 둘을 함께 모아 보세요.

## 새로 생긴 것

### 🚩 길드 마크

- 길드장이 **12가지** 중에서 고릅니다 — 별 · 몬스터볼 · 불꽃 · 물방울 · 잎 · 번개 · 왕관 · 달 · 검 · 날개 · 발자국 · 하트
- 고른 마크는 **홀 깃발**의 방패, **길드 이름 앞**, **길드 목록**에 길드 색으로 찍힙니다
- 방 › 길드 › 🏗️ 홀 꾸미기 위의 "🚩 길드 마크" 줄에서 바꿉니다(무료). 다른 길드원은 지금 마크를 볼 수 있습니다

### 🏗️ 새 홀 장식 (길드원이 함께 모금)

| 장식 | 🪙 | 자리 |
|---|---|---|
| 🏮 등불 줄 | 300 | 깃발과 샹들리에 사이 천장 아래 — 밤엔 붉게 빛난다 |
| 📚 길드 서재 | 400 | 오른쪽 벽 앞 책장과 지구본 |
| 🛋️ 라운지 소파 | 500 | 분수 오른쪽, 길드 색 천 |
| 🎹 그랜드 피아노 | 900 | 왼쪽 바닥, 뚜껑을 연 피아노와 의자 |
| 🐠 벽 수족관 | 1100 | 간판 아래 벽, 물고기 넷 |

### 🖼️ 새 홀 배경

- **🎓 서울대 캠퍼스(노을)** 🪙50 — 보랏빛에서 주황으로 지는 하늘, 지는 해를 등진 정문 실루엣, 불 켜진 학교 건물, 관악산 능선
- **🌸 벚꽃 정원** 🪙2500 — 벚나무 · 나무 울타리 · 꽃잎 흩날리는 잔디

### 모금함 정리

- 다 모인 장식은 맨 위에 "완성 n / 16" 한 줄로 접고, 모금 중인 것만 카드로 보입니다(많이 모인 순)
