# PokeTokenBar 0.9.0

모은 **코인(🪙)으로 방을 꾸밉니다** — 코인으로만 사는 배경 3개와 가구 10개가 생겼습니다.
방의 가구를 **끌어서 옮길** 수 있고, 포켓몬 **이름표를 늘 띄워** 둘 수 있습니다.

0.8.0 다음 버전입니다.

## 새로 생긴 것

### 🪙 코인 꾸미기 — 방 탭 "🪙 코인 꾸미기" 칸

0.8.0 에서 코인이 생겼지만 쓸 곳은 길드 몰뿐이었습니다. 이제 코인으로만 사는 꾸미기가 있습니다.
**설정 › 온라인 기능을 켜야** 삽니다(코인은 서버 지갑에 있습니다).

| 배경 | |
|---|---|
| 포켓몬센터 — 흰 벽, 몬스터볼 무늬 빨간 띠, 분홍 징두리 | 🪙1000 |
| 체육관 배틀필드 — 천장 조명, 양옆 깃발, 초록 필드 | 🪙1200 |
| 하늘기둥 — 우주와 초록 오로라, 낡은 돌기둥 | 🪙1500 |

| 가구 | | 포켓몬은 |
|---|---|---|
| 몬스터볼 벽시계 | 🪙80 | 지금 시각을 가리킨다 |
| 네온사인 | 🪙120 | 깜빡인다. 밤에도 밝다 |
| 잠만보 빈백 | 🪙300 | 큰 아이도 올라가 앉거나 낮잠, 밤엔 거의 잔다 |
| 주크박스 | 🪙350 | 앞에서 춤춘다 |
| 아케이드 게임기 | 🪙400 | 양옆에 한 마리씩 붙어 게임한다 |
| 벽난로 | 🪙450 | 앞에 앉아 불을 쬔다 — 불 타입이 잘 온다 |
| 잉어킹 연못 | 🪙500 | 첨벙 — 물 타입이 잘 온다 |
| 포켓몬센터 회복기 | 🪙600 | 들러서 분홍빛으로 회복한다 |
| 마스터볼 진열대 | 🪙800 | 구경한다 |
| 전설 석상 | 🪙1000 | 구경한다. **내가 가진 전설의 모습**으로 깎인다(전설이 있어야 산다) |

- 한 번 더 눌러야 사지고, **되팔 수 없습니다** — 쓴 코인은 그대로 사라집니다(코인 값이 계속 오르지 않게)
- 산 것은 위 배경 · 가구 목록에 들어가 사탕 가구처럼 놓기 / 치우기 합니다
- 산 것은 **서버 지갑이 기억합니다.** 세이브를 고쳐 넣어도 길드 방에는 보이지 않습니다
- 그림은 모두 기존 방처럼 도트로 직접 그렸습니다. 불꽃 · 음표 · 게임기 화면 · 네온 · 회복기 불빛 · 잉어킹이 움직입니다
- 코인 가구는 이미 놓인 가구 · 벽 장식과 겹치지 않는 자리를 스스로 찾아 섭니다

### ✋ 가구 옮기기

- 방 아래 **✋ 가구 옮기기** 를 누르면 가구에 점선이 생기고, 끌어서 옮길 수 있습니다. **✓ 다 옮김** 으로 끝냅니다
- 바닥 가구는 바닥 안에, 벽시계 · 네온은 벽 안에 머뭅니다. **↺ 처음 자리로** 로 모두 되돌립니다
- 포켓몬도 옮긴 가구를 따라갑니다 — 침대에서 자기, 쿠션에 앉기, 화분 앞, TV 앞 자리. 램프 불빛 · 어항 물고기도
- 길드원에게도 옮긴 대로 보입니다
- 창문 · 러그 · 포스터는 벽지에 그려져 있어 옮기지 않습니다

### 🏷️ 이름표 늘 보이기

- 방의 포켓몬 이름표를 늘 띄웁니다. 길드원의 방을 볼 때도 같습니다(길드 홀은 이미 주인 이름표가 떠 있습니다)

## 이 앱이 보내는 것 — 바뀐 것 있음

기본 설정(온라인 기능 꺼짐)에서는 **바뀐 것이 없습니다.**

**온라인 기능을 켜고** 쓸 때 같은 중계 서버(Cloudflare Workers)에 다음이 더해집니다.

| 보내는 것 | 언제 |
|---|---|
| 산 코인 꾸미기(물건 이름) | 코인 꾸미기를 살 때 |
| 길드 방 사진에 — 옮긴 가구 자리, 전설 석상의 모델(도감 번호) | 길드에 들어가 있을 때, 방을 올릴 때 |
| 지갑 열쇠(산 것인지 확인용 — 저장하지 않음) | 방에 코인 꾸미기를 놓고 길드에 방을 올릴 때만 |

토큰 사용 기록(로그), 파일 경로, 세이브는 보내지 않습니다.
