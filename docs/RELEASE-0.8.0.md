# PokeTokenBar 0.8.0

**전설의 포켓몬**이 야생에 나타납니다 — 뮤츠, 뮤, 루기아, 레쿠쟈, 아르세우스… 그리고 **메타몽**이 변신합니다.
**코인(🪙)**이 생겼고, 길드원끼리 포켓몬을 사고파는 **길드 몰**과 박스 정리용 **상점에 팔기**가 들어왔습니다.

0.7.0 다음 버전입니다.

  포획률도 원작대로 낮아서(뮤츠 3) 결투로 약하게 만들고 하이퍼볼을 써야 잡을 만합니다. 나타나면 알림이 따로 뜹니다
- 잡으면 처음부터 그 모습이고, 토큰을 쓰면 레벨만 오르다 **마스터에서 이로치**가 됩니다
- **메타몽의 변신** — 결투에서 원작처럼 상대의 타입 · 능력치(HP 빼고) · 랭크 · 기술을 복사하고, 모습도 상대 그림으로 바뀝니다
- 상점의 "전설 알"은 진짜 전설과 헷갈리지 않게 **"희귀 알"**로 이름을 바꿨습니다(★4 이상 확정은 그대로)

### 🪙 코인 · 🛒 길드 몰 · 🐾 상점에 팔기 — 상점 탭 위 "🏪 상점 | 🛒 길드 몰"

사탕과 따로 **코인**이 있습니다. 코인은 서버가 잔액을 들고 있어서 가짜 결제나 두 번 쓰기가 안 됩니다.
**설정 › 온라인 기능을 켜야** 씁니다. 상점 탭을 처음 열면 지갑이 저절로 생깁니다.

| 코인 버는 곳 | |
|---|---|
| 출석 | 🪙10, 하루 한 번 |
| 사탕 환전 | 🍬1 → 🪙5, 하루 사탕 5개까지 |
| 상점에 팔기 | 하루 10마리 · 🪙100까지 |
| 몰 판매 대금 | 판매가 − 수수료 5% |
| 길드 주간 보상 | 지난주 1위 🪙50, 칭호마다 🪙10 |

- **🛒 길드 몰** — 같은 길드원끼리 포켓몬을 코인으로 사고팝니다. 올리면 내 박스에서 빠져 서버가 맡고, 팔리면 산 사람에게
  갑니다. 판 사람이 꺼져 있어도 대금은 바로 들어갑니다. 🪙1~9999, 한 사람 5마리까지, 7일 안에 안 팔리면 돌아옵니다.
  매물마다 레벨 · 개체값 · 성격 · 특성 · 패시브스킬이 보이고, 올릴 때 참고 가격(상점 판매가 · 최근 거래가)을 보여 줍니다
- **교환 진화는 몰로** — 윤겔라 · 근육몬 · 고우스트 등 원작에서 교환으로 진화하는 아이는 **몰에서 데려오는 순간** 진화합니다
- **🐾 상점에 팔기** — 박스가 꽉 찰 때. 인기 없는 아이를 상점이 바로 사 줍니다. 값은 희귀도 × 진화 단계 × 이로치(전설은 기본 🪙15).
  좋은 아이는 몰에서 사람에게 파는 게 더 받습니다
- 길드를 나가거나 내보내지면 몰에 맡긴 아이는 저절로 돌려받습니다

## 바뀐 것 · 없어진 것

- **교환 보내기가 없어졌습니다** — 길드 몰이 그 자리를 맡습니다. 이미 받은 교환 코드(`PTBT-…`)는 다음 몇 버전 동안
  결투 탭에서 받을 수 있습니다
- **끝난 주는 고칠 수 없습니다** — 길드 순위의 지난주 기록을 나중에 덮어쓰지 못하게 서버가 막습니다
- **부계정으로 코인 모으기 막기** — 계정이 없어 지갑은 몇 개든 만들 수 있어서, 처음 지원금이 없고(지갑만 만들어서는 코인이
  안 생깁니다), 같은 인터넷 주소에서 하루 5개까지만 만들고, **새 지갑은 만든 지 이틀이 지나야 몰에서 살 수 있습니다**(파는 건 바로)

## 이 앱이 보내는 것 — 바뀐 것 있음

기본 설정(온라인 기능 꺼짐)에서는 **바뀐 것이 없습니다.**

**온라인 기능을 켜고 코인 · 몰을 쓸 때** 같은 중계 서버(Cloudflare Workers)에 다음이 더해집니다.

| 보내는 것 | 언제 |
|---|---|
| 지갑 번호 · 출석 날짜 · 환전한 사탕 수 | 출석 · 환전할 때 |
| 상점에 판 아이(종 · 성장량 · 이로치) | 상점에 팔 때 |
| 몰에 올린 아이(교환 코드와 같은 내용 — 종 · 개체값 · 성격 · 특성 · 기술 · 성장량)와 가격 | 몰에 올릴 때 |
| 지갑 번호(길드 방 사진에) | 길드 주간 코인 보상을 넣으려고 |

토큰 사용 기록(로그), 파일 경로, 세이브는 보내지 않습니다. 지갑을 만들 때 인터넷 주소는 저장하지 않고 하루 개수를 세는 데 해시로만 씁니다.

## 알려진 한계

- **친선 · 실시간 · 길드 결투는 둘 다 0.8.0 이어야 합니다** — 종 · 기술 데이터와 결투 규칙(변신)이 바뀌었습니다. 0.7.0 에서
  등록해 둔 친선 코드는 다시 등록해 주세요. 길드 구경 · 순위는 버전이 달라도 됩니다
- **길드 몰은 같은 길드 안에서만** 돌아갑니다. 모든 사용자가 쓰는 전체 몰은 부계정 막기를 더 단단히 한 뒤에 엽니다
- 사탕 · 포켓몬은 각자의 세이브에 있어 조작을 완전히 막을 수 없습니다 — 그래서 환전 · 상점에 팔기에 하루 한도가 있고,
  몰은 길드(아는 사람) 안에서만, 낯선 길드원은 길드장이 내보낼 수 있습니다
- 코인 지갑의 열쇠는 세이브에 있습니다. 세이브를 잃으면 지갑도 잃습니다(세이브 자동 백업에 같이 들어갑니다)
