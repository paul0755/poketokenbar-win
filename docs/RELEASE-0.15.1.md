# PokeTokenBar 0.15.1

**사탕 · 💠 비트가 안 쌓이던 것을 고쳤습니다.** 0.15.0 다음 버전입니다. 서버는 바뀌지 않았습니다.

---

## 고친 것

### 사탕 · 비트가 깎이거나 멈추던 것

- **원인** — 사탕(디지털 월드의 비트)을 PC 에 **지금 남아 있는 로그의 토큰 합계**로 셌습니다.
  그런데 Claude Code 는 30일 지난 대화 로그를 스스로 지웁니다. 지워질 때마다 합계가 줄어 그만큼 사탕이 깎였고,
  날마다 지워지는 양만큼 쓰는 사람은 사탕이 아예 안 쌓이는 것처럼 보였습니다. 앱을 쓴 지 30일이 넘은 사람부터 생깁니다
- **이제** — 로그를 읽을 때마다 **늘어난 만큼만** 데이터 폴더의 `tokens.json`(토큰 장부)에 더해 두고, 사탕 · 비트는 그걸로 셉니다.
  로그가 지워져도 장부는 줄지 않습니다
- 업데이트하는 순간 **가진 사탕 · 비트는 그대로**이고, 거기서부터 이어서 쌓입니다

### 누적 토큰이 줄어 보이던 것

- 트레이 툴팁의 "누적"과 홈 › 도구별 탭(Claude Code · Codex)의 누적 · 입력 · 출력 · 캐시도 장부로 셉니다. 로그가 지워져도 줄지 않습니다
- 로그가 다 지워진 도구도 탭에 남습니다

### 세계를 오갈 때

- 두 세계가 장부 하나를 같이 씁니다. 다른 세계에 가 있던 동안 옛 로그가 지워져도, 돌아오면 그 사이 쓴 만큼을 다 따라잡습니다

## 설치

`PokeTokenBar-Setup-0.15.1.exe`를 받아 실행하세요. 쓰던 세이브는 그대로 이어집니다.
이전 버전 위에 그대로 설치하면 됩니다. 0.14.4 이상을 쓰고 있으면 앱의 🆕 새 버전 알림에서 바로 받을 수 있습니다.

코드 서명이 없어 **"Windows에서 PC를 보호했습니다"** 창이 뜨면 **추가 정보 → 실행**을 누르세요.

## 알려진 한계

- **이미 깎인 사탕 · 비트는 돌아오지 않습니다** — 지워진 로그는 다시 셀 수 없습니다
- 장부는 앱이 켜져 있을 때 채워집니다. **앱을 30일 넘게 꺼 두면** 그 사이 지워진 몫은 셀 수 없습니다

- 실시간 배틀 · 길드원과의 결투는 둘 다 0.14.0 이상이어야 합니다
