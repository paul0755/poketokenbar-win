# PokeTokenBar 0.20.1

**⭐ 박스의 전설만 버튼을 켜도 별이 보입니다.**
0.20.0 에서는 켜면 버튼이 노란색이 되어, 노란 ⭐ 이 바탕에 묻혀 사라진 것처럼 보였습니다.
이제 켜면 **진한 호박색 바탕 · 금테 · 금색 글자**가 됩니다. ♥ 즐겨찾기만(분홍)과도 한눈에 갈립니다.

0.20.0 다음 버전입니다. 서버는 바뀌지 않았습니다.
결투 규칙은 그대로라 **0.20.0 과 친선 · 실시간 · 길드 결투가 됩니다.**

## 설치

`PokeTokenBar-Setup-0.20.1.exe`를 받아 실행하세요. 쓰던 세이브는 그대로 이어집니다.
이전 버전 위에 그대로 설치하면 됩니다. 0.14.4 이상을 쓰고 있으면 앱의 🆕 새 버전 알림에서 바로 받을 수 있습니다.
