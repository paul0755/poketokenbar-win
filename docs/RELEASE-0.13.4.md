# PokeTokenBar 0.13.4

결투 탭이 **🌐 온라인 탭**이 되었습니다. 안에서 **⚔️ 결투 · 🔁 교환**으로 나뉘고,
결투 화면은 원작 배치를 빌려 **상대는 오른쪽 위, 내 아이는 뒷모습으로 왼쪽 아래**에 섭니다.
피오네와 마나피는 서로 진화하지 않는 환상의 포켓몬으로 나뉘었습니다.

0.13.3 다음 버전입니다. **서버도 함께 바뀌었습니다(이미 배포됨).**

---

## 바뀐 것

### 🌐 온라인 탭 — 결투 · 교환

- 결투 탭 한 줄에 늘어놓았던 연습 결투 · 친선 배틀 · 실시간 배틀 · 교환 받기 · 가방을 정리했습니다.
  방 탭처럼 안에서 **⚔️ 결투 · 🔁 교환** 둘로 나눕니다
- **⚔️ 결투 — 실시간 배틀**
  - **내 포켓몬 VS 상대** 카드 — 그림 · 별 · 레벨 · 타입이 보이고, 내 카드를 누르면 박스 아이들을 그림으로 골라 바꿉니다
  - 방 만들기 · 코드 참가를 한 줄에, 방 코드는 크게. 방에 들어가면 준비 · 나가기만 남습니다
- **🔁 교환** — 예전 교환 코드(PTBT-…)를 붙여 넣으면 오는 아이를 카드로 먼저 보여 줍니다(교환 진화하면 무엇이 되는지도).
  새 교환은 **길드 몰 열기** 버튼으로 바로 갑니다
- 연습 결투는 지금처럼 **바탕화면에서 펫을 끌어 다른 펫 위에 놓으면** 됩니다 — 이기면 나무열매(하루 5번).
  열매 개수는 박스 › 상세에서 보입니다
- 코드를 손으로 주고받던 **친선 배틀 칸은 빠졌습니다** — 실시간 배틀이 같은 결투를 더 쉽게 합니다

### ⚔️ 결투 화면

- 상대는 **오른쪽 위에 앞모습**, 내 아이는 **왼쪽 아래에 뒷모습**(5세대 애니메이션 · 이로치 포함)
- 이름 · 체력 상자는 각자 반대편 구석에, 아래에는 **한 글자씩 찍히는 대사 창** — "망나뇽이 승부를 걸어왔다!" "가랏, 비리디온!"
- 양쪽에서 미끄러져 들어오고, 끝나면 **이겼다 / 졌다**를 크게 보여 줍니다. 전체 기록은 아래에서 펼쳐 봅니다
- 메타몽이 변신하면 상대의 모습을 그대로 빌립니다. **길드원과의 결투**도 같은 화면입니다

### 피오네 · 마나피

- 피오네가 알에서 나와 80M 에 마나피로 진화했습니다 — 원작에서 둘은 서로 진화하지 않는 **환상의 포켓몬**입니다
- 이제 둘 다 진화 없는 환상의 포켓몬입니다(피오네 ★4 · 마나피 ★5). 알에서는 안 나오고 **야생에서만** 만납니다
- **마나피 모습까지 자란 아이는 마나피로 남습니다.** 덜 자란 아이는 피오네로 남습니다(처음 켤 때 한 번)
- 레이드 보스 순서는 바뀌지 않았습니다 — 둘은 레이드 보스 · 전설의 조각에서 빠집니다
