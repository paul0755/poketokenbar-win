# PokeTokenBar 0.15.2

**사탕(💠 비트)이 0개에 묶여 있던 분께 모자란 만큼 채우고, 사과로 10개를 더 드립니다.** 0.15.1 다음 버전입니다. 서버는 바뀌지 않았습니다.

---

## 고친 것

### 0.15.1 로도 0개에서 안 움직이던 사탕 · 비트

- 0.15.0 까지는 사탕을 남은 로그 합계로 셌습니다. Claude Code 가 30일 지난 로그를 지우면 "번 사탕"이 줄어
  **"쓴 사탕"보다 적어지는** 세이브가 생겼습니다. 화면에는 0개로만 보이고, 그 모자란 만큼을 다시 벌 때까지 아무리 써도 0개였습니다
- 0.15.1 은 사탕이 더 깎이지 않게 했지만, **이미 생긴 모자란 몫은 그대로 남아** 있었습니다

## 새로 생긴 것

### 🍬 사과 보상 (한 번)

- 업데이트한 뒤 처음 켤 때, 쓴 사탕이 번 사탕보다 많으면 **모자란 만큼을 채워 0개로 맞추고, 사과로 10개를 더** 드립니다.
  산 물건은 그대로이고, 그 순간부터 25M 마다 바로 사탕이 생깁니다
- 디지털 월드의 💠 비트도 같습니다(세이브마다 따로)
- 받으면 Windows 알림이 한 번 옵니다(설정에서 알림을 껐으면 알림 없이 들어갑니다). 모자란 몫이 없던 세이브는 바뀌지 않습니다
- 세이브마다 한 번만 받습니다
