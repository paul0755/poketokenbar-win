## 다른 사용자와 배틀·교환

토큰으로 키운 포켓몬을 친구와 싸움 붙이거나 주고받는다.

### 이미 준비된 것

- **결투가 난수를 바깥에서 받는다** (`battle.run` 의 `rng`). 두 사람이 같은 씨앗을 쓰면
  각자 PC에서 똑같은 결투가 나온다. 서버가 결투를 대신 돌릴 필요가 없다.
- **한 마리가 작다.** 종·성격·이로치·개체값·성별·특성·패시브스킬·기술머신·성장량이
  150자 남짓. 복사해 붙이는 코드나 QR로 충분하다.
- **Lv.50 맞추기**가 있어서 키운 시간이 달라도 공정하게 싸울 수 있다.

### 원칙과 부딪히는 곳

이 앱은 "토큰 집계는 네트워크를 쓰지 않고, 사용량을 어디로도 보내지 않는다"를
약속한다(README "보내는 것"). 그래서 단계를 나눈다.

**1단계 — 서버 없이 코드 주고받기.** 앱은 여전히 아무것도 보내지 않는다.
사람이 코드를 복사해 메신저로 보낸다.

**2단계 — 작은 중계 서버(선택).** 설정에서 켜야만 동작한다. 보내는 건 포켓몬 데이터와
닉네임뿐 — 토큰 기록은 절대 보내지 않는다. README "보내는 것" 표를 고친다.

### 1단계 — 코드 주고받기

- **친선 배틀** ✅ — 결투 탭에서 내 팀을 등록하면 코드가 나온다. 친구가 붙여 넣으면
  Lv.50 으로 싸운다. 씨앗을 두 코드에서 만들기 때문에 서로 코드를 바꿔 넣으면
  **두 PC에서 똑같은 결투**가 나오고, 다시 돌려서 결과를 바꿀 수도 없다.
  보상(나무열매)은 없다 — 가짜 코드로 열매를 찍어 낼 수 있기 때문이다.
- **교환** — 보낼 아이를 코드로 만들면 내 박스에서 빠지고, 친구가 넣으면 받는다.
  같은 코드를 두 번 받지 못하게 받은 코드를 기록한다.

### 2단계 — 중계 서버

- 6자리 방 코드로 둘이 접속한다. 서버는 서로의 팀과 씨앗만 전한다. 결투 계산은 양쪽 PC.
- 교환은 서버가 "양쪽 다 보냈다"를 확인한 뒤 동시에 넘긴다(한쪽만 받고 끝나지 않게).
  교환 번호로 같은 아이를 두 번 받는 것도 막는다.
- 후보: Cloudflare Workers + Durable Objects (웹소켓 방, 무료 구간).

### 막을 수 없는 것 — 그래서 "친선"이다

- **조작.** 세이브가 내 PC의 파일이라 마음먹으면 Lv.100 이로치 전설을 만들어 넣을 수
  있다. 서버가 있어도 "토큰을 진짜 썼는지"는 확인할 길이 없다. 순위전은 맞지 않는다.
  말이 안 되는 데이터(개체값 31 초과, 그 종이 못 배우는 기술)만 데이터 사전으로 거른다.
- **교환 복제.** "보내고 → 백업으로 되돌리기"면 한 마리가 둘이 된다. 서버가 있으면
  같은 교환을 두 번 받는 건 막지만 완전히 막지는 못한다. 친선 모드라 감수한다.
- **데이터 버전.** 앱 버전(데이터 파일)이 다르면 같은 씨앗이라도 결과가 갈린다.
  코드에 데이터 버전을 넣고, 다르면 업데이트하라고 막는다.

### 더하면 좋을 것

1. **교환 진화** — 원작처럼 교환하면 진화하는 아이들이 데이터에 있다
   (캐이시→윤겔라→후딘, 알통몬→근육몬→괴력몬, 꼬마돌→데구리→딱구리, 고오스→고우스트→팬텀).
   이 앱은 토큰으로 진화하니 "교환하면 다음 단계까지 남은 양을 채워 준다" 같은 보너스로 살린다.
2. **3대3 배틀** — 지금 결투는 1대1이라 대인전에는 단조롭다. 팀과 교체를 넣는다(결투 계산에 교체 추가).
3. **친구 도감 비교** — 코드 하나로 서로의 도감·전적을 비교한다.
4. **바탕화면 방문** — 친구의 포켓몬이 내 바탕화면에 손님으로 하루 놀다 간다.
5. **배틀 리플레이 공유** — 같은 씨앗 덕분에 결투 기록을 코드로 보내 그대로 다시 재생할 수 있다.
6. **미스터리 선물** — 1:1 교환 대신 아무나 받을 수 있는 선물 코드.
