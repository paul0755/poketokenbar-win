# PokeTokenBar 0.21.1

**💎 옆으로 넓은 메가가 바탕화면 펫에서 작아 보이지 않습니다.**
펫 창은 정사각형이라, 3D 메가 그림이 옆으로 넓으면 폭에 묶여 키가 줄었습니다.
메가리자몽X 는 다른 펫의 3분의 2, 메가보만다 · 메가피존투는 절반도 안 되는 키로 떴습니다.

이제는 그런 메가가 떠 있는 동안(🔥 버닝 타임의 메가 · 마스터의 늘 메가):

- 펫 창이 **그림 비율만큼 옆으로 넓어집니다**. 높이는 그대로라 키가 다른 펫과 같습니다
  (예: 펫 크기 128 일 때 메가리자몽X 190 · 메가갸라도스 197 · 메가라티아스 294 · 메가보만다 320)
- 아주 넓은 메가는 **펫 크기의 2.5배**에서 멈춥니다
- 메가가 끝나면 **제자리에서** 다시 정사각형으로 돌아옵니다(가운데가 그대로)
- 돌아다니기 · 끌어 놓기 · 펫끼리 결투 · 야생 결투에서 나란히 서는 자리도 넓어진 폭으로 셉니다

0.21.0 다음 버전입니다. 서버는 바뀌지 않았습니다.
결투 규칙은 그대로라 **0.20.x · 0.21.0 과 친선 · 실시간 · 길드 결투가 됩니다.**

## 설치

`PokeTokenBar-Setup-0.21.1.exe`를 받아 실행하세요. 쓰던 세이브는 그대로 이어집니다.
이전 버전 위에 그대로 설치하면 됩니다. 0.14.4 이상을 쓰고 있으면 앱의 🆕 새 버전 알림에서 바로 받을 수 있습니다.

코드 서명이 없어 **"Windows에서 PC를 보호했습니다"** 창이 뜨면 **추가 정보 → 실행**을 누르세요.

```
SHA-256  a3d5446558fec954323cd32e6541a457253d8640d11a247c79f8251559514597
```

## 알려진 한계

- 펫 여러 마리를 나란히 띄운 채 하나가 넓어지면 **옆 펫과 조금 겹칠 수 있습니다**. 돌아다니기 시작하면 흩어집니다
- 넓어진 창의 투명한 곳도 **클릭을 받습니다**(그 아래 창을 누르려면 펫을 조금 옮기세요)
- 결투 중의 메가진화(⚡ 에너지)는 창을 넓히지 않습니다. 정사각형 창에서 그림을 조금 키워 보여 줍니다
- 앱에 있는 종의 **남은 메가 14종**(Z-A 본편 5종 · DLC 9종)은 아직 없습니다. 3D 그림(앞 · 뒤 · 이로치)이 올라오면 넣습니다
- 0.18.x 를 쓰는 사람에게는 강화로 **위험예지(숨김)를 받은 너트령**이 "말이 안 되는 값"으로 보입니다(몰 매물 · 교환)
