# PokeTokenBar 0.22.0

**🎖️ 칭호가 생겼습니다.** 해낸 일로 저절로 얻고, 하나를 골라 이름 앞에 답니다.

- 레이드 보스에게 마지막 한 방을 먹이면 **🗡️ 막타 장인**, 방을 열 번 꾸미면 **🛋️ 집꾸미기 장인**,
  체육관 배지 여덟 개를 모으면 **🏅 배지 콜렉터** — 모두 23개입니다(README "🎖️ 칭호"에 목록과 조건)
- 한 번 얻으면 없어지지 않습니다. 이미 해 둔 일(배지 · 졸업 · 도감 · 누적 토큰 …)은 업데이트하자마자 칭호가 되고 알림이 뜹니다
- 방 탭 › **🎖️ 칭호** 에서 얻은 것을 누르면 이름 앞에 달립니다(다시 누르면 뗍니다). 못 얻은 칭호는 접어 두었다가 펼치면 조건과 지금 몇인지 보입니다
- 단 칭호는 **내 방 이름판 · 길드원 목록 · 주간 순위 · 길드 홀 이름표(아이콘만) · 레이드 · 실시간 결투**에 보입니다

**🏠 방 탭을 정리했습니다.** 방 그림 아래가 길게 이어지던 것을 **🎨 꾸미기 · 🐾 포켓몬 · 🎖️ 칭호 · 📜 기록** 탭으로 나눴습니다.
고른 탭은 기억하고, 내 방 이름판을 누르면 칭호 탭이 열립니다.

**📦 박스**
- **📌 맨 위 고정** — 그림 오른쪽 위의 📌 를 누르면 정렬과 상관없이 박스 맨 위(즐겨찾기보다 위)에 섭니다. 먼저 고정한 아이가 위
- **💎 메가만** — ⭐ 전설만 옆. 메가스톤을 지닌 아이만 모아 봅니다

**고친 것**
- 🏛️ **명예의 전당** — 대표 포켓몬을 바꾸면 지난 주들의 그림까지 지금 대표로 바뀌던 것. 이제 주마다 그 주의 대표가 남습니다
- 💎 결투가 끝난 뒤 바탕화면의 **메가 펫이 작아지던** 것

0.21.1 다음 버전입니다. 서버는 이미 바뀌어 있습니다(칭호 · 그 주의 대표를 주고받음).
결투 규칙은 그대로라 **0.20.x · 0.21.x 와 친선 · 실시간 · 길드 결투가 됩니다** — 옛 버전 상대에게는 내 칭호가 보이지 않을 뿐입니다.

## 설치

`PokeTokenBar-Setup-0.22.0.exe`를 받아 실행하세요. 쓰던 세이브는 그대로 이어집니다.
이전 버전 위에 그대로 설치하면 됩니다. 0.14.4 이상을 쓰고 있으면 앱의 🆕 새 버전 알림에서 바로 받을 수 있습니다.

코드 서명이 없어 **"Windows에서 PC를 보호했습니다"** 창이 뜨면 **추가 정보 → 실행**을 누르세요.

```
SHA-256  2430132b9b29f3c02c62bb203b0f3dc725cd42ebc25f40c75a7329b7bf214ad1
```

## 알려진 한계

- 칭호는 **0.22.0 이상 앱에만** 보입니다. 옛 버전 길드원 화면에는 이름만 나옵니다
- 레이드 막타는 **이 버전부터** 셉니다. 방 꾸미기 횟수는 업데이트할 때 가진 배경 · 가구 수에서 시작합니다
- 칭호는 **세계마다 따로**입니다(포켓몬 세계 · 디지털 월드는 세이브가 따로). 길드 · 레이드는 포켓몬 세계 기준입니다
- 박스 📌 고정은 **이 PC 에만** 기억합니다(정렬처럼)
- 명예의 전당에서 **이 버전 전에 끝난 주**는 그 주의 대표가 기록되지 않아 지금 대표로 보입니다
- 앱에 있는 종의 **남은 메가 14종**(Z-A 본편 5종 · DLC 9종)은 아직 없습니다
