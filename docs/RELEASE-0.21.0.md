# PokeTokenBar 0.21.0

**💸 쓴 토큰이 원화로 얼마인지, ⚔️ 도감에서 타입 상성을 볼 수 있습니다.**

## 💸 토큰을 원화로

Claude Code 사용량을 요청마다 **Claude API 정가**로 쳐서 원화로 보여 줍니다.

- **홈** — 오늘 · 이번 주 · 이번 달 숫자 아래, 그리고 일별 그래프에서 고른 날에 `≈ ₩…`
- **도구 탭(Claude Code)** — 누적을 정가로 친 값(달러도 함께). 가격표 없는 모델이 섞이면 그만큼 빠졌다고 적습니다
- 요청마다 모델과 토큰 종류(입력 · 출력 · 캐시 쓰기 5분/1시간 · 캐시 읽기)를 따로 셉니다 — 2026-11 단가표
- 장부에도 달러 누적을 둬서, 30일 지난 로그가 지워져도 누적이 줄지 않습니다
- 숫자에 마우스를 올리면 어떻게 셌는지와 환율이 나옵니다

구독(Pro · Max)으로 쓰면 실제로 내는 돈은 정액입니다. 여기 숫자는 **"같은 양을 API 로 썼다면"의 값**입니다.
**Codex · Gemini 는 가격표가 없어 원화로 세지 않습니다.**

환율은 [Frankfurter](https://frankfurter.dev)(유럽중앙은행 고시)에서 12시간마다 받습니다. 보내는 것은 없습니다.
못 받으면 지난 값을, 한 번도 못 받았으면 $1 = ₩1,350 으로 칩니다(이때는 "기본값"이라고 적습니다).

## 🏰 길드 합계에 원화 추정

길드 화면 📊 이번 주 토큰 순위의 **길드 합계 옆에 `≈ ₩… 추정`** 이 붙습니다.
서버에는 길드원의 토큰 수만 있고 어떤 모델을 썼는지는 없어서, **내 이번 주 단가**(정가로 친 원 ÷ 토큰)를 길드 합계에 곱한 어림입니다.
캐시 읽기가 많은 사람 · Codex 를 쓰는 사람이 많으면 실제와 다릅니다. 내 Claude 기록이 없으면 보이지 않습니다.

## ⚔️ 도감에 상성표

도감 탭 위의 **📖 도감 / ⚔️ 상성표** 로 바꿉니다.

- **계산기** — 타입을 하나나 둘 고르면 그 타입이 받는 기술을 ×4 · ×2 · ×½ · ×¼ · ×0 으로 나눠 보여 줍니다.
  하나만 고르면 그 타입 기술로 칠 때 효과가 굉장한 상대도, 둘을 고르면 두 타입 기술 중 하나로 효과가 굉장한 상대도
- **상성 바퀴** — 18타입이 대표 포켓몬과 함께 한 원에 섭니다. 타입을 누르면 🔵 강한 상대로 → , 🟠 약한 상대에게서 ← 화살표가,
  안 맞는 상대는 점선으로. 아무것도 안 고르면 모든 "효과가 굉장한" 관계가 옅게 보입니다
- 결투가 쓰는 상성표(`types.json`)와 같은 표입니다. 디지털 월드엔 없습니다

0.20.2 다음 버전입니다. 서버는 바뀌지 않았습니다.
결투 규칙은 그대로라 **0.20.x 와 친선 · 실시간 · 길드 결투가 됩니다.**

## 알려진 한계

- 원화는 **Claude 만**입니다. Codex · Gemini 는 가격표가 없습니다
- 단가표는 앱에 적어 둔 2026-11 정가입니다. Anthropic 이 가격을 바꾸면 다음 버전까지 옛 가격으로 셉니다
