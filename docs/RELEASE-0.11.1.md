# PokeTokenBar 0.11.1

**길드에 들어가 있어도 길드 목록을 둘러봅니다.** 그리고 길드 코인 보상을 여러 길드에서 겹쳐 받던 틈을 막았습니다.

0.11.0 다음 버전입니다.

---

## 새로 생긴 것

### 🔎 다른 길드 보기 — 길드 화면 아래

- 길드에 들어가 있어도 **🔎 다른 길드 보기** 로 길드 목록을 엽니다(찾기 · ↻ 다시 불러오기 · ✕ 닫기)
- **내 길드**에는 노란 테두리와 "내 길드"가 달립니다
- 다른 길드의 들어가기는 흐리게 보이고, 누르면 **지금 길드를 나간 뒤 들어갈 수 있다**고 알려 줍니다
  (한 번에 한 길드에만 있을 수 있습니다). 지금 길드는 그대로입니다
- 내 길드가 목록에 없으면 알려 줍니다 — 길드장에게는 아래 📋 길드 목록에 올리기로 올릴 수 있다고
- 길드장이 목록에 올리기를 바꾸면 열려 있는 목록에도 바로 반영됩니다

---

## 바뀐 것

- **길드 코인 보상은 지갑 하나당 한 주에 길드 하나에서만** 받습니다(서버 — 이미 적용됨).
  계정이 없어서 세이브를 하나 더 쓰면 같은 지갑으로 여러 길드에 들어가 길드마다 주간 1위 · 칭호 · 공동 목표
  보상을 받을 수 있었습니다. 이제 지갑이 그 주 보상을 준 길드를 기억하고, 같은 주 보상을 다른 길드가 넣으려 하면
  넘깁니다. **앱을 그대로 쓰는 사람에게는 바뀌는 게 없습니다**(한 번에 한 길드라서)
- 좁은 창에서 길드 화면 아래 버튼 줄이 넘치면 다음 줄로 내려갑니다

---

## 이 앱이 보내는 것 — 바뀐 것 없음

0.11.0 과 같습니다. "다른 길드 보기"는 0.11.0 의 길드 찾기와 같은 목록을 받아 오기만 합니다.

## 설치

`PokeTokenBar-Setup-0.11.1.exe`를 받아 실행하세요. 쓰던 세이브는 그대로 이어집니다.
이전 버전 위에 그대로 설치하면 됩니다.

코드 서명이 없어 **"Windows에서 PC를 보호했습니다"** 창이 뜨면 **추가 정보 → 실행**을 누르세요.

```
SHA-256  1e2d0644bee85e7f3973e6eeec38a6c5f3492264fc83fecc7fae89745f3af264
```

## 알려진 한계
