# PokeTokenBar 0.14.8

**트레이 아이콘을 찾지 않아도 됩니다.** 어디서든 **Ctrl + Alt + P** 로 팝오버가 열리고 닫힙니다.

0.14.7 다음 버전입니다. 서버는 바뀌지 않았습니다.

---

## 새로 생긴 것

### ⌨️ 팝오버 단축키

- 어디서든 **Ctrl + Alt + P** 를 누르면 팝오버가 열리고, 한 번 더 누르면 닫힙니다
- **설정 › 일반 › ⌨️ 팝오버 단축키** — 버튼을 누르고 새 조합을 누르면 바로 바뀝니다. Esc 는 취소
- Ctrl · Alt · Win 중 하나는 함께 눌러야 합니다(글자만 누르는 조합은 타자 칠 때마다 팝오버가 떠서 받지 않음). F 키는 혼자도 됩니다
- 다른 프로그램이 이미 쓰는 조합이면 설정에 그렇게 알려 줍니다. **끄기**로 끌 수 있습니다

### 🔄 새 버전 지금 확인

- **📢 새 소식** 오른쪽 위의 **🔄 새 버전 확인** — 결과가 바로 아래 글자로 나옵니다(최신 · 새 버전 · 확인 못 함)
- **트레이 우클릭 › 🔄 새 버전 확인** — 결과를 Windows 알림으로 알려 줍니다
- ✕ 로 접어 둔 버전도 직접 확인하면 띠가 다시 펴집니다

## 바뀐 것

- **절전에서 깨면 새 버전을 다시 확인합니다**(마지막 확인에서 1시간이 지났으면). 6시간 간격도 절전 동안 멈췄다 밀리지 않게, 실제 흐른 시간으로 셉니다

## 고친 것

- **배율이 다른 화면을 오가면 팝오버가 점점 커지던 것** — 노트북(125%)과 모니터(100%)처럼 배율이 다를 때,
  노트북 화면에 팝오버를 띄우면 Windows 가 창을 1.25배로 키우고 그 크기가 저장돼 켤 때마다 커졌습니다.
  이제 테두리를 손으로 끌어 바꾼 크기만 기억하고, 띄울 때마다 그 크기로 맞춥니다(화면보다 크면 화면 안으로)
- **설정 › 한도에 `300M` · `1.5B` 처럼 넣으면 못 읽고 비우던 것** — 이제 `300M` · `1.5b` · `2,000,000` 모두 읽습니다
