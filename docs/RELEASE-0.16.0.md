# PokeTokenBar 0.16.0

**💎 메가진화가 들어옵니다.** 메가스톤을 지닌 아이가 결투에 나가면 ⚡ 메가 에너지 하나로 메가진화합니다.

0.15.2 다음 버전입니다. 서버는 바뀌지 않았습니다. 디지털 월드는 그대로입니다.

---

## 새로 생긴 것

### 💎 메가진화 54종

- 원작 메가진화 46종과 **Z-A 의 새 메가 8종**(메가픽시 · 메가우츠보트 · 메가아쿠스타 · 메가망나뇽 · 메가메가니움 · 메가장크로다일 · 메가무장조 · 메가염무왕)
- 리자몽 · 뮤츠는 X · Y 둘. 엘레이드 · 눈여아는 이 앱의 종 목록에 없어서 빠졌습니다
- 메가진화하면 **타입과 종족값**(HP 빼고)이 바뀝니다. 개체값 · 성격 · 레벨 · 기술은 그대로입니다. 특성은 결투 규칙에 없어서 바뀌지 않습니다
- 흑백 도트에는 메가 모습이 없어서 **Showdown 의 3D 모델**로 바뀝니다

### 메가진화 컷인

- 메가진화할 때 디지털 월드 필살기처럼 **비스듬한 띠가 열리고**, 원래 모습이 들어와 키스톤 빛과 함께 깜빡이다가 하얗게 터지며 3D 메가 모습이 됩니다. 반대쪽에서 "망나뇽나이트 ✦ 메가진화 / 메가망나뇽"이 들어옵니다
- 결투 · 체육관 · 챔피언 로드 · 친선 · 실시간 · 길드 결투의 결투 화면과 레이드 방에서 나옵니다. 건너뛰기를 누르면 컷인도 건너뜁니다
- 이름 상자도 "나의 메가망나뇽"처럼 바뀝니다

### 💎 메가스톤

- 상점에서 **🍬10**. 박스에 있는 라인의 돌만 나옵니다
- **박스 › 상세 › 지닌 물건**에서 지니게 합니다. 변하지않는돌 · 빛가림돌과 같은 칸이라 하나만 지닙니다
- 진화 전에도 미리 지닐 수 있습니다(파이리 + 리자몽나이트X). 메가진화는 그 종이 된 뒤에 합니다
- 교환하면 같이 가고, 몰에 올리거나 팔거나 놓아주면 가방으로 돌아옵니다

### ⚡ 메가 에너지

- 토큰 **5000만**마다 하나, **5개**까지. 처음엔 0개에서 시작합니다. 가득 찬 동안 쓴 토큰은 쌓이지 않습니다
- 메가진화 **한 번에 하나**. 배틀 탭 위 줄에서 남은 에너지를 보고 **💎 메가진화 쓰기**를 켜고 끕니다(끄면 돌을 지녀도 메가진화하지 않고 에너지도 안 씁니다)
- 한 쪽에 **한 번에 하나**만 메가진화해 있습니다. 메가진화한 아이가 이겨 다음 판으로 가면 메가인 채로, 쓰러지면 다음 아이가 할 수 있습니다

### 어디서 메가진화하나

| | 에너지 |
|---|---|
| 바탕화면 결투 (펫 끌어 놓기) | 씀 — 둘 다 내 아이라 둘 다 하면 2개 |
| 🏟️ 체육관 · 🏆 챔피언 로드 | 씀 |
| 🐉 레이드 | 씀 — 내 아이만(길드원 · 보스는 하지 않음) |
| 친선 · 실시간 배틀 · 길드원과의 결투 | **안 씀** — 지닌 돌만 있으면. 두 PC 가 같은 판을 계산하는데 상대의 에너지는 알 수 없습니다 |
| 야생 포켓몬 | 하지 않음 |

### 챔피언 누리의 에이스

- 에이스 망나뇽이 **메가진화한 내 아이와 마주치면** 맞받아 메가진화합니다
- 메가를 쓰지 않으면 챔피언은 전과 같습니다(Lv.100 여섯 마리 시뮬레이션으로 확인)

### 🔥 버닝 타임의 펫 메가진화

- 버닝 타임에 **10분 안에 500만**을 쓰면, 맞는 메가스톤을 지닌 바탕화면 펫이 **10분 동안** 3D 메가 모습이 됩니다
- 보여 주기라 에너지를 쓰지 않습니다. 앱을 다시 켜면 끝납니다

### 도감 💎

- 메가진화하는 종의 칸에 💎가 붙습니다. 칸에 마우스를 올리면 메가 모습의 이름이 나옵니다
