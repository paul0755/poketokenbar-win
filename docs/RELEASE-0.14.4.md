# PokeTokenBar 0.14.4

**새 버전이 나오면 앱이 알려 줍니다.** 2단 진화 라인의 가짜 "3차 진화"를 없애고, 레이드에서 길드원의 아이도 쓰러지면 다음 아이가 이어 나옵니다.

0.14.3 다음 버전입니다. **서버도 함께 바뀌었습니다(이미 배포됨).**

---

## 새로 생긴 것

### 🆕 새 버전 알림

- 켤 때(15초 뒤)와 6시간마다 GitHub 의 가장 최근 릴리스를 확인합니다 — 설치 파일(.exe)이 올라간 릴리스만 칩니다
- 새 버전이 있으면 팝오버 위에 초록 띠, Windows 알림(버전마다 한 번), 트레이 메뉴의 **🆕 새 버전 받기**가 나옵니다
- **받기**를 누르면 릴리스 페이지가 열립니다. 저절로 깔지는 않습니다. ✕ 를 누르면 그 버전은 더 알리지 않습니다
- 보내는 것은 GitHub 에 "가장 최근 릴리스가 뭐냐"는 요청 하나뿐입니다(토큰 기록 등은 보내지 않음)
- 이 기능은 **0.14.4 부터** 들어 있습니다 — 0.14.3 이하는 이번 한 번은 직접 받아 주세요

### 🐉 레이드 — 길드원의 아이도 쓰러지면 다음 아이가

- 앱이 길드에 대표 말고 **레이드 후보 5마리**(박스에서 많이 자란 순)를 함께 올립니다
- 남의 도전에서 길드원의 대표가 쓰러지면, 그 턴이 끝날 때 **그 사람의 후보가 그 자리에** 저절로 나옵니다(길드원마다 따로 5마리)
- 후보가 깎은 칸은 그 주인의 기록입니다
- 0.14.3 이하 길드원은 후보를 올리지 않아 지금처럼 대표 한 마리뿐입니다

## 바뀐 것

### 🎓 2단 진화는 9억에 마스터

가디 → 윈디처럼 **2차 진화에서 마지막 모습이 되는 라인(143개)** 이 4억에서 모습은 그대로인 채 "3차 진화"를 하던 문제를 고쳤습니다.

| | 1차 | 2차 | 3차 | 마스터(졸업) |
|---|---|---|---|---|
| 3단 진화 (파이리 → 리자드 → 리자몽) | 500만 | 8000만 | 4억 | 15억 |
| **2단 진화 (가디 → 윈디)** | 500만 | 8000만 | **없음** | **9억** (Lv.60 무렵) |
| 진화 없는 종 | | | | 15억 그대로 |

- **이미 9억을 넘긴 2단 진화 아이**는 업데이트 후 처음 켤 때 한꺼번에 졸업합니다(박스의 아이까지, 졸업마다 사탕 +5, 알림 한 번)
- 상점이 사 주는 값도 같은 단계로 셉니다(서버 반영됨)
