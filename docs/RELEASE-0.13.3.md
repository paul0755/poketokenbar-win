# PokeTokenBar 0.13.3

상점에 **🥚 전설의 알**이 생겼습니다. 진화 단계 이름은 **1차 · 2차 · 3차 진화**로 바뀌고,
별 등급은 진화 단계 수로 한 번 더 묶습니다.

0.13.2 다음 버전입니다. **아직 0.13.1 을 쓰고 있다면 꼭 올려 주세요** — 야생이 2차 진화 모습으로 나오던 것은 0.13.2 부터 고쳐져 있습니다.

---

## 새로 생긴 것

### 🥚 전설의 알

- **상점 › 전설의 알 🍬60, 한 주에 1개.** 전설 35종 중 하나가 깨어납니다.
  환상의 포켓몬(뮤 · 세레비 등 11종)은 지금처럼 야생에서만 만납니다
- 박스에 **알로** 들어오고, 다른 알처럼 **5M** 을 쓰면 깨어납니다. 그다음은 레벨만 오르다 마스터에서 이로치
- 진주빛 은색에 무지개 띠를 두른 알입니다 — 박스 · 홈에서도 이 그림으로 보입니다
- 한 주 제한은 마스터볼과 따로 셉니다. 월요일에 다시 살 수 있습니다
- 레이드 조각(5개 → **고른** 전설)은 그대로입니다. 알은 **무작위** 전설입니다

---

## 바뀐 것

### 진화 단계 이름

| 누적 토큰 | 예전 | 이제 |
|---|---|---|
| 5M | 부화 | **1차 진화** |
| 80M | 1차 진화 | **2차 진화** |
| 400M | 최종 진화 | **3차 진화** |
| 1.5B | 마스터 | 마스터 |

- 2단 진화 라인(꼬렛 → 레트라)은 2차 진화에서 마지막 모습이 되고, 3차 진화는 같은 모습입니다
- 0.13.2 에서 야생에서 잡은 아이에게 붙이던 **"야생에서 잡음"** 은 뺐습니다 — "부화"라는 이름 때문에 붙였던 것이라,
  이제 야생에서 잡은 니드런도 "1차 진화"로 보입니다

### ⭐ 별 등급 — 3단 진화는 ★3 이상, 2단 진화는 ★3 까지

- 포획률만으로 정하면 스라크 · 만타인 · 이브이(2단)가 스타팅(3단)과 같은 ★4 였고, 니드런 · 구구 · 캐터피(3단)는 ★1 이었습니다
- 이제 **3단 진화 77개는 모두 ★3 이상**, **2단 진화 144개는 ★3 까지**입니다. 진화 없는 종은 포획률 그대로
- 일반 알 확률이 달라집니다 — ★1 79 → 60% · ★3 3 → 27% · ★4 9 → 5.5% · ★5 0.1 → 0.2%
- **희귀 알(★4 이상)은 늘 3단 진화**(스타팅 · 미뇽 · 애버라스 등)가 나옵니다
- **잡힐 확률과 상점 판매가는 그대로**입니다 — 원작 포획률로 셉니다

## 고친 것

- 진화 없는 종이 알에서 시작할 때 단계 이름이 "전설의 포켓몬"으로, 진행률이 마스터 기준으로 나오던 것 — 알은 "알"로, 5M 까지의 진행률로
