# PokeTokenBar 0.13.5

박스에 **정렬**과 **♥ 즐겨찾기**가 생겼습니다.

0.13.4 다음 버전입니다.

---

## 새로 생긴 것

### 정렬

- 박스 위의 **정렬** 메뉴 — 받은 순 · 최근 받은 순 · 레벨 높은 순 · 별 많은 순 · 많이 자란 순 · 이름 순 · 도감 번호 순
- 알은 레벨 · 이름 · 도감 번호 순에서 맨 뒤로 갑니다
- 고른 정렬은 기억합니다 — 앱을 다시 켜도 그대로입니다

### ♥ 즐겨찾기

- 그림 왼쪽 위의 **♡** 를 누르면 즐겨찾기 — **어느 정렬에서나 박스 맨 위**에 모입니다
- 즐겨찾기한 아이는 **놓아주기 · 상점에 팔기 · 길드 몰에 올리기가 막힙니다.** 아끼는 아이를 실수로 잃지 않게.
  풀려면 ♥ 를 다시 누르세요
- **♥ 즐겨찾기만** 으로 즐겨찾기한 아이만 모아 봅니다
