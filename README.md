# PokeTokenBar for Windows

AI 코딩 도구에 쓴 토큰으로 포켓몬을 키우는 Windows 트레이 앱 + 바탕화면 펫.

[chattymin/PokeTokenBar](https://github.com/chattymin/PokeTokenBar) (macOS, MIT)의 아이디어를
Windows로 옮긴 것입니다. 원본 코드를 이식한 게 아니라 새로 만들었습니다 —
원본은 Swift/SwiftUI라 Windows에서 UI 레이어를 통째로 다시 써야 합니다.

---

## 설치

### 받아서 쓰기

[Releases](../../releases)에서 `PokeTokenBar-Setup-x.y.z.exe` 를 받아 실행합니다.
설치는 **사용자 계정 단위**라 관리자 권한이 필요 없습니다.

> **"Windows에서 PC를 보호했습니다" 창이 뜹니다.**
> **추가 정보 → 실행** 을 누르면 설치됩니다.
>
> 코드 서명 인증서가 없어서 생기는 경고입니다(연 수십만 원). 개인 프로젝트라
> 구입하지 않았습니다. 찜찜하시면 아래처럼 소스에서 직접 빌드해 쓰세요.

### 소스에서 실행

Node.js 20 이상이 필요합니다.

```bash
git clone https://github.com/paul0755/poketokenbar-win.git
cd poketokenbar-win
npm install
npm start
```

`npm start` 에서 `Electron failed to install correctly … node_modules\electron\index.js` 가 나면
Electron 실행 파일이 덜 받아진 것입니다(npm 이 설치 스크립트를 막았거나 내려받기가 끊긴 경우).
`npm install` 뒤와 `npm start` 앞에 저절로 확인해 다시 받으니 보통은 한 번 더 `npm start` 하면 됩니다.
그래도 안 되면 지우고 다시 받으세요.

```bash
npm run fix-electron
```

회사망·백신이 GitHub 내려받기를 막으면 이것도 실패합니다. 그때는 Releases 의 설치 파일을 쓰세요.

설치 파일 만들기:

```bash
npm run dist
```

## 이 앱이 읽는 것 · 보내는 것

개인 작업 기록을 다루는 앱이라 먼저 밝힙니다.

**읽는 것** — 이미 PC에 있는 로컬 로그 파일뿐입니다.

| 도구 | 경로 | 상태 |
|---|---|---|
| Claude Code | `~/.claude/projects/**/*.jsonl` | ✅ |
| Codex | `~/.codex/sessions/**/*.jsonl` | ✅ |
| Codex (opencodex 프록시 경유) | `~/.opencodex/usage.jsonl` | ✅ (opencodex 사용 시. 세션 로그와 겹치는 요청은 한 번만 셉니다) |
| Codex 주간 쿼터 | `~/.opencodex/codex-quota-cache.json` | ✅ (opencodex 사용 시) |
| Gemini | — | ❌ Antigravity 로그에 토큰 수가 없음 |
| Copilot | — | ❌ `.copilot` 전체에 토큰 필드 없음 |

읽는 건 **토큰 개수와 시각뿐**입니다. 대화 내용·코드·파일 경로는 쓰지 않습니다.

경로는 자동으로 찾습니다(`CLAUDE_CONFIG_DIR`, XDG 위치, 데스크톱 임베디드 세션 포함).
못 찾거나 다른 곳에 두셨으면 **설정 › 읽는 곳**에서 더할 수 있습니다 —
기본 경로를 대체하지 않고 추가로 읽습니다.

**사용률(%) 막대는 환경에 따라 뜨지 않을 수 있습니다.** 도구가 제 사용률을
파일로 남겨 줄 때만 읽을 수 있기 때문입니다.

| 출처 | 파일 | 조건 |
|---|---|---|
| Claude | `%APPDATA%/Claude/plan-usage-history.json` | **데스크톱 앱**을 쓸 때. CLI만 쓰면 없습니다 |
| Claude (스토어판) | `%LOCALAPPDATA%/Packages/Claude_*/LocalCache/Roaming/Claude/…` | MSIX 설치본은 여기에 씁니다 |
| Codex | `~/.opencodex/codex-quota-cache.json` | opencodex 프록시를 쓸 때 |
| Codex | 세션 로그의 `rate_limits` | 응답에 값이 실려 올 때 |

**5시간 막대가 자주 비는 이유** — Claude 데스크톱 앱은 사용률을 앱이 켜질 때와
한도에 막혔을 때만 적습니다(측정해 보니 하루 1~2회). 그래서 대부분은 몇 시간 묵은
값이고, 그런 값으로는 지금 몇 %인지 알 수 없어 막대를 그리지 않습니다.

실시간으로 보려면 [clanker-usage](https://github.com/wakamex/clanker-usage)
(`pip install ccusage`)를 설치하고 데몬을 띄우면 됩니다. 이 앱은 그 도구가
`~/.cache/clanker-usage/` 에 떨궈 둔 결과 파일을 읽습니다. **설치는 선택이고,
없으면 예전과 똑같이 동작합니다.**

> 그 도구는 사용률을 받아오려고 `~/.claude/.credentials.json` 을 읽고 토큰을
> 갱신합니다. **이 앱은 인증 정보에 손대지 않습니다** — 결과 파일만 읽습니다.
> 설치 여부는 직접 판단하세요. 그래서 필수로 걸지 않았습니다.
>
> npm 에도 같은 이름(`ccusage`)의 다른 도구가 있는데, 그쪽은 로컬 로그 토큰
> 집계용이라 한도가 나오지 않습니다. 이 앱이 이미 하는 일이기도 합니다.

막대가 없어도 앱은 정상 동작합니다 — 쓴 양이 숫자로 나오고,
**설정 › 한도 맞추기**에서 지금 몇 %인지 한 번 넣으면 막대가 생깁니다.
파일 위치가 다르면 **설정 › 읽는 곳**에서 직접 고를 수 있습니다.

**보내는 것** — 기본으로는 포켓몬 스프라이트를 받는 요청 하나뿐입니다.

```
GET https://raw.githubusercontent.com/PokeAPI/sprites/...
```

처음 보는 포켓몬이 나올 때만 받고 디스크에 캐시합니다.
**토큰 집계는 네트워크를 전혀 쓰지 않습니다.** 사용량 데이터를 어디로도 보내지 않고,
분석 도구도 없습니다.

**온라인 기능(실시간 배틀 · 길드)을 켰을 때만** 하나가 더 생깁니다 — 설정 › 온라인 기능, 기본은 꺼짐.

| 보내는 곳 | 보내는 것 | 보내지 않는 것 |
|---|---|---|
| 중계 서버(`server/`, Cloudflare Workers) | 방 코드, 내 팀 코드(포켓몬 한 마리의 종·개체값·기술 등), 트레이너 이름 | 토큰 사용 기록, 로그, 파일 경로, 세이브 |
| 같은 서버의 길드 (들어갔을 때만) | 트레이너 이름, 방 꾸미기(배경·가구), 방에 둔 포켓몬(종·모습·레벨·이로치), 도감·졸업·승수·주간 1위 횟수, 대표 팀 코드, **이번 주·오늘 토큰 합계와 그중 버닝타임 몫·시간대별(아침·코어·야근·새벽) 몫**(길드 순위·칭호 — 길드 화면에서 끌 수 있음) | 토큰 사용 기록(로그), 도구별·요청별 내역, 파일 경로, 세이브 |

실시간 배틀 방은 같은 방의 두 사람에게 팀 코드와 시작 시각을 전달만 하고 **아무것도 저장하지 않습니다.**
길드는 길드원이 꺼져 있어도 방을 볼 수 있어야 해서 위의 "방 사진"을 **저장합니다.** 길드를 나가면 내 칸은 바로 지워지고,
마지막 사람이 나가면 길드도 없어집니다.
결투 계산은 두 앱이 각자 합니다. 서버 코드는 이 저장소의 [`server/`](./server) 에 있고,
다른 서버를 쓰고 싶으면 설정에서 주소를 바꿀 수 있습니다.

**저장하는 것** — `%APPDATA%\PokeTokenBar\` 에 `save.json`(진행 상황),
`backups/`(세이브 백업), `sprites/`(이미지 캐시)만 만듭니다.

백업은 하루 한 번, 그날 처음 저장하기 직전의 세이브를 남깁니다(최근 7일).
진행 초기화나 되돌리기 직전의 판도 따로 남깁니다(최근 5개).
**설정 › 백업에서 되돌리기**에서 고르면 앱이 다시 켜지며 그 시점으로 돌아갑니다.

이 폴더는 **설정 › 저장 폴더 바꾸기**에서 옮길 수 있습니다. 다른 드라이브에
두거나 통째로 백업하고 싶을 때, 그리고 `%APPDATA%` 가 가상화되는 환경
(MSIX/AppX 샌드박스 안에서 도는 도구 등)에서 같은 경로가 서로 다른 파일을
가리키는 걸 피하고 싶을 때 씁니다. 바꾸면 쓰던 세이브를 한 번 가져오고,
다시 켜야 적용됩니다. `POKETOKENBAR_DATA` 환경변수로도 지정할 수 있으며
이쪽이 우선합니다.

## 되는 것

**트레이**
- 아이콘은 앱 로고(설정에서 현재 포켓몬으로 바꿀 수 있음)
- 툴팁에 오늘 / 누적 토큰, 다음 진화까지 남은 양
- 우클릭 메뉴 — 펫 · 도감 · 설정 · 새로고침 · 종료

**메인 창** — 홈 / 상점 / 박스 / 방 / 결투 / 도감 (트레이 클릭 또는 펫 클릭 · Esc로 닫기)

창 테두리를 끌어 **크기를 바꿀 수 있습니다**(최소 400×460, 크기는 기억). 넓히면 홈은 두 단,
상점·박스·도감은 여러 칸으로 펼쳐지고 방은 창 높이에 맞춰 커집니다.

- **홈** — 스프라이트·레벨·타입·등급·성격, 진화 트리, 진행바,
  오늘/이번 주/이번 달, 이번 달 일별 그래프(막대를 눌러 그날 고정)
- **도구별 탭** — Claude Code / Codex 를 오가며 입력·출력·캐시 분해 확인
- **한도** — 고른 도구의 5시간 블록·주간. 한도를 아는 경우에만 남은 %를 그립니다
- **박스** — 보유한 아이들. 키우는 아이 바꾸기 · 바탕화면에 세우기 · 놓아주기.
  줄을 누르면 **개체 상세**가 펼쳐집니다
- **방** — 미니룸. 배경·가구를 사서 꾸미고 포켓몬을 둡니다. 아래 참고
- **결투** — 박스의 두 아이를 싸움 붙입니다. 아래 참고
- **도감** — 614칸, 전국도감 번호 순. 만난 종만 그림·이름이 보입니다

**개체 상세** — 레벨 · 성별 · 타입 · 특성(설명 포함) · 개체값 · 능력치 · 배운 기술 · 패시브스킬 · 기술머신

능력치는 원작 계산식 그대로입니다(노력치 0). 개체값은 받는 순간 0~31로 정해져 저장되고,
성격 보정(±10%)도 원작과 같습니다. 기술은 5세대(BW) 것만 씁니다 —
스프라이트가 5세대라 다른 세대를 섞으면 그 시절에 없던 기술이 나옵니다.

- **레벨업 기술** — 원작처럼 가장 최근에 배운 넷
- **패시브스킬** — 원작의 알기술입니다. 받는 순간 그 종이 물려받을 수 있는 것 중 1~2개가 정해지고, 진화해도 갑니다
- **기술머신** — 상점에서 사면 키우는 아이가 배울 수 있는 것 중 하나를 무작위로 익힙니다

**바탕화면 펫**
- 투명 창, 항상 위, 작업표시줄에 안 뜸
- **여러 마리 동시에** 띄울 수 있습니다
- 클릭하면 팝오버, 드래그하면 이동 (4px 이하 움직임은 클릭으로 침). 다른 펫 위에 놓으면 결투
- 천천히 배회 — 가만히 있기 / 가끔 / 자주
- **기술 쓰기** — 아는 기술(레벨업 넷 · 패시브스킬 · 기술머신) 중 하나를 씁니다. 토큰을 써서
  키우는 아이가 자랐을 때, 새 기술을 배웠을 때(`NEW`), 가만히 있을 때 가끔.
  몸은 분류대로(물리 돌진 · 특수 기 모으기 · 변화 번쩍임), 효과는 타입 색으로 그립니다.
  기술 이름으로 **전용 연출**이 붙습니다 — 물기는 이빨, 빔은 광선, 펀치는 충격 별,
  지진은 창이 흔들리고, 째려보기는 눈빛, 잠자기는 Zzz. 24종으로 기술 약 3/4(396/514)이 걸리고,
  위력이 셀수록 크게 터집니다.
  공격 모션 스프라이트는 쓸 만한 라이선스로 배포되는 곳이 없어 가진 그림으로 합성했습니다

**게임**
- **614종** (1~5세대) — 진화 라인 221개 + **진화 없는 종 95개**
- **진화 없는 종 · 전설** — 뮤츠 · 뮤 · 루기아 · 칠색조 · 레쿠쟈 · 아르세우스 같은 전설·환상 46종과 메타몽 · 켄타로스 ·
  라프라스 같은 진화 없는 종. **알에서는 안 나오고 야생에서만** 만납니다(전설은 출현의 0.5% 남짓, 포획률도 원작대로 낮음).
  잡으면 처음부터 그 모습이고, 레벨만 오르다 마스터에서 이로치가 됩니다
- **메타몽** — 결투에서 원작처럼 **변신**: 상대의 타입 · 능력치(HP 빼고) · 랭크 · 기술을 복사하고 모습도 바뀝니다
- **포획률 기반 가중 뽑기** — 공식 포획률을 5등급으로 묶어 희귀한 게 실제로 희귀합니다
- **성격 25종** — 오른/내린 능력치가 실제 능력치에 반영됩니다
- 5단계: 알 → 부화 → 1차 진화 → 최종 진화 → 마스터(이로치)
- **이상한사탕** — 25M 쓸 때마다 1개. 졸업하면 5개 추가
- **🔥 버닝타임** — 코어 타임(10~16시)·야근 시간(18시~자정)에 쓴 토큰은 **성장 ×4**(기본 켜짐).
  기록마다 쓴 시각으로 나눠서, 앱을 꺼 둔 동안 쓴 것도 제 시간대대로 칩니다. 나무열매와 겹치면 더해집니다
- **상점** — 알 3종(일반 🍬2 / 슈퍼 ★3확정 🍬7 / 희귀 ★4확정 🍬18) ·
  이상한사탕 🍬1 · 민트 🍬2 · 기술머신 🍬3 · 변하지않는돌 🍬3 · 슈퍼볼 3개 🍬1 · 하이퍼볼 3개 🍬2 · 반짝이는 부적 🍬60
- **이로치** — 부화 시 1/128, 부적을 사면 1/64
- **졸업** — 마스터까지 키우면 도감에 기록되고 사탕 5개를 받습니다

**알림** (진화 · 졸업 · 한도 임박) — 상태가 바뀐 순간에만 뜹니다

**설정**
- **난이도** — 성장 속도 10~200%(높을수록 빨리 자람) · 상점 가격 10~200% ·
  버닝타임(배수 ×2~×4, 두 구간 시간, 평일만)
- **한도 맞추기** — 아래 설명 참고
- 알림 · 트레이 아이콘 · 펫 크기(64~320px) · 움직임 · 기술 쓰기 · 야생 포켓몬(안 나오기 / 가끔 / 자주)
- 갱신 주기(30초~10분) · 로그인 시 자동 시작
- 저장 폴더 열기 · 백업에서 되돌리기 · 진행 초기화

## 결투 · 나무열매

박스에서 두 마리를 골라 싸움 붙입니다. 기술은 각자 알아서 고르고, 화면은 그걸 재생합니다.

- **원작 규칙 그대로** — 5세대 데미지 공식, 자속 1.5배, 타입 상성, 급소, 난수,
  우선도(전광석화가 먼저), 능력치 랭크(±6), 마비·화상·독·잠듦·얼음·혼란, 풀죽음,
  흡수·반동, 연속기. 숫자는 전부 PokéAPI 에서 받은 값입니다
- **레벨** — 기본은 둘 다 **Lv.50으로 맞춥니다**(원작 배틀시설처럼). 능력치만 다시 계산하고
  기술은 아는 그대로라 개체값·성격·기술 구성으로 승부가 갈립니다. 평균 6턴쯤 갑니다.
  "실제 레벨로"를 고르면 레벨 차이 그대로 싸웁니다
- **빠진 것** — 특성(153개가 저마다 다른 규칙), 지닌 물건, 날씨, 교체, PP.
  카운터·대타출동처럼 효과가 숫자로 오지 않는 기술은 효과 없이 지나갑니다
- 승패와 보상은 앱 본체가 끝까지 계산해서 정합니다. 화면은 재생만 합니다 — "건너뛰기"를 눌러도 결과는 같습니다

**바탕화면 결투** — 결투 탭의 **바탕화면에서** 버튼, 또는 바탕화면에서 **펫을 끌어 다른 펫 위에 놓으면**
두 펫이 마주 서서 싸웁니다(Lv.50). 머리 위에 HP 막대와 "효과가 굉장했다!" 같은 짧은 말이 뜨고,
이긴 쪽은 뛰어오르고 진 쪽은 잠시 뒤 일어납니다. 바탕화면에 없던 아이는 결투 동안만 나왔다가
돌아갑니다. 규칙·보상은 탭과 같고, 결과는 알림으로 옵니다

**친선 배틀** — 서버 없이 친구와 싸웁니다. 결투 탭에서 내 팀을 등록하면 `PTB1-…` 코드
한 줄이 나옵니다. 메신저로 친구에게 보내고, 친구 코드를 받아 붙여 넣으면 Lv.50으로 싸웁니다.

- 난수 씨앗과 좌우를 두 코드에서 정해서, 서로 코드를 바꿔 넣으면 **두 PC에서 똑같은 결투**가
  나옵니다. 같은 두 코드로는 몇 번을 해도 같은 결과입니다(다시 돌려 결과를 바꿀 수 없습니다)
- 앱 버전(데이터)이 다르면 같은 결투가 나오지 않으므로 막습니다
- 말이 안 되는 값(개체값 31 초과, 그 종이 못 배우는 기술 등)은 받지 않습니다. 다만 세이브가
  각자 PC의 파일이라 조작을 완전히 막을 수는 없습니다 — 그래서 **보상이 없는 친선**입니다
- 앱은 여전히 아무것도 보내지 않습니다. 코드는 사람이 복사해서 보냅니다

**교환** — 결투 탭에서 보낼 아이를 고르면 박스에서 빠지고 `PTBT-…` 코드가 나옵니다.
친구가 붙여 넣으면 받습니다. 같은 코드는 한 번만 받을 수 있고, 실수로 보냈으면 그 코드를 내가
다시 받으면 돌아옵니다. 받는 아이는 보낸 사람 화면과 같은 모습·레벨로 도착합니다.

- **교환 진화** — 원작에서 교환으로 진화하는 아이(윤겔라→후딘, 근육몬→괴력몬, 데구리→딱구리,
  고우스트→팬텀, 롱스톤→강철톤, 스라크→핫삼 등 18개 라인)는 받는 순간 진화합니다.
  받기 전에 미리 알려 줍니다. 목록은 PokéAPI 진화 체인에서 뽑습니다

**실시간 배틀** — 친구와 같은 결투를 두 화면에서 동시에 봅니다(설정 › 온라인 기능을 켜야 합니다).
결투 탭에서 **방 만들기**를 누르면 6자리 코드가 나옵니다. 친구가 그 코드로 **참가**하고 둘 다
**준비**를 누르면, 서버가 정한 시각에 같은 결투가 함께 시작합니다. 실시간 배틀 칸의 **내 포켓몬**에서
고른 아이로 싸우고(Lv.50), 보상은 없습니다. 방 안에서도 포켓몬을 바꿀 수 있습니다 — 한쪽이 바꾸면
상대 화면에도 바로 보이고 둘 다 다시 준비를 눌러야 시작합니다. 상대가 나가면 알려 줍니다.

**나무열매** — 이기면 하나를 받습니다(**하루 5번까지**). 무화·위키·마고·아바·파야열매,
맛이 하나씩입니다. 박스에서 아이를 펼쳐 먹이면 그 아이의 **토큰 경험치가 2배**가 됩니다.

| | 2배로 쳐 주는 양 |
|---|---|
| 좋아하는 맛 | 4000만 토큰 |
| 그 외 | 2000만 토큰 |
| 싫어하는 맛 | 안 먹습니다 (열매는 남습니다) |

좋아하는 맛은 원작처럼 성격이 정합니다 — 올려 주는 능력치의 맛을 좋아하고 내리는 쪽을
싫어합니다(공격 매운맛 · 방어 신맛 · 특공 떫은맛 · 특방 쓴맛 · 스피드 단맛).
아무리 먹여도 1억 토큰까지만 쌓입니다.

보상에 상한을 둔 이유 — 결투는 공짜 버튼이라 상한이 없으면 열매를 무한히 모아
토큰을 안 써도 자라게 됩니다. "실제로 쓴 토큰만 화폐"라는 원칙을 지킵니다.

## 야생 포켓몬

바탕화면에 아무 때나 **처음 보는 포켓몬이 불쑥 나타납니다**. 화면 아래 가운데에 몬스터볼이 뜨면
마우스로 잡고 야생 포켓몬 쪽으로 **휙 던지세요**. 놓는 순간의 방향·세기로 포물선을 그립니다.

- 맞으면 볼에 빨려 들어가 원작처럼 **세 번 흔들리고**, 다 버티면 잡힙니다. 잡은 아이는
  부화한 모습으로 박스에 들어갑니다
- 포획 확률은 5세대 공식 그대로입니다 — 몬스터볼 한 번에 꼬렛 44%, 미뇽 12%, 전설 2% 쯤.
  볼 왼쪽 위에 **지금 던지면 잡힐 확률**이 나옵니다
- 출현마다 몬스터볼 3개. 빗나간 볼은 돌아옵니다. 튀어나올 때마다 도망칠 수 있고(귀할수록 잘 도망),
  3분이 지나면 떠납니다
- **약하게 만들기** — 내 펫을 끌어 야생 위에 놓으면 싸웁니다(둘 다 Lv.50). 펫은 야생 체력이
  40% 아래로 떨어지면 공격을 멈추고, 쓰러뜨릴 것 같은 기술은 피하고 상태이상 기술을 즐겨 씁니다.
  깎인 체력과 상태이상(잠듦·얼음 2.5배, 마비·화상·독 1.5배)만큼 잘 잡힙니다 — 평균 35% → 62%.
  그래도 급소로 쓰러뜨리면 잡을 수 없습니다
- **슈퍼볼(1.5배)·하이퍼볼(2배)** — 상점에서 3개씩(🍬1 · 🍬2). 볼을 끌지 않고 **누르면** 종류가 바뀝니다
- 도감에 없는 종이면 `NEW` 가 붙습니다
- **언제 나오나** — 토큰과 상관없이 무작위입니다. 가끔은 1~3시간(하루 4번까지),
  자주는 20~60분(하루 10번까지). 자리를 비운 동안(5분 이상 입력 없음)에는 나오지 않고 미룹니다.
  설정 › 펫 › 야생 포켓몬, 또는 트레이 메뉴의 **야생 포켓몬 부르기**로 바로 불러낼 수 있습니다(오늘 몫에서 빠집니다)
- **방해 금지 시간** — 설정 › 펫에서 켜고 시간을 고르면(자정을 넘겨도 됩니다) 그 사이에는 저절로 나오지 않고
  끝난 뒤로 미룹니다. 회의·발표 중에 튀어나오면 곤란할 때. 직접 부르는 건 막지 않습니다

하루 상한을 둔 이유 — 잡은 아이는 공짜 알입니다. 알은 사탕 2개입니다.

### 길드

방 탭 위의 **🏰 길드** 로 넘어갑니다. 설정 › 온라인 기능을 켜야 합니다.

- **만들기 / 코드로 들어가기** — 만들면 `GLD-ABCD2345` 코드가 나옵니다. 친구에게 알려 주세요.
  한 번에 한 길드, 길드당 30명까지
- **방 구경** — 길드원을 누르면 그 사람의 방이 그대로 뜹니다. 배경·가구·포켓몬·기록 장식까지.
  내 방을 꾸미면 길드에도 저절로 올라갑니다(바뀐 게 있을 때, 1분에 한 번까지)
- **결투** — 길드원이 올려 둔 대표 포켓몬(그 사람 방의 첫 아이)과 Lv.50 친선 배틀. 상대가 꺼져 있어도 됩니다.
  보상은 없습니다. 친선 배틀처럼 둘 다 같은 버전이어야 합니다
- **📊 이번 주 토큰 순위** — 길드원끼리 이번 주(월요일 0시부터) 쓴 토큰을 겨룹니다. 길드 합계, 오늘 1위,
  🔥 버닝타임 MVP도 나옵니다. 1위의 포켓몬은 길드 홀에서 👑 를 쓰고 다니고, 게시판에 이름이 걸립니다.
  올라가는 건 합계 셋(이번 주 · 오늘 · 그중 버닝타임 몫)뿐입니다. **"내 토큰 합계 공개"를 끄면** 아예 보내지 않고
  순위에 "비공개"로 나옵니다(기본은 켜짐). 길드원의 앱이 켜져 있을 때 몇 분마다 올라갑니다
- **🏛️ 명예의 전당** — 주가 끝나면(월요일 0시) 그 주의 1위와 칭호가 남습니다. 주차별로 1위의 포켓몬·사용량과
  칭호 보유자, 맨 위에 통산 1위 횟수. 길드 서버가 최근 26주를 보관하고, 길드를 나가면 내 기록은 모든 주에서 지워집니다
- **주간 칭호** — 👑 토큰왕 · 🔥 버닝 MVP · ☀️ 코어타임 장인(10~16시) · 🌙 야근왕(18~24시) · 🦉 올빼미(0~6시) ·
  🌅 아침형(6~10시). 지난주 칭호는 한 주 동안 길드 홀 이름표와 순위에 달리고, 게시판에 지난주 1위가 걸립니다.
  시간대별 합계도 길드 순위와 같은 공개 설정을 따릅니다
- **🏅 주간 1위 메달** — 길드에서 한 주 1위를 하면 내 방 벽에 메달 액자가 걸립니다(횟수 표시)
- **길드장** — 만든 사람. 길드원을 내보낼 수 있습니다. 길드장이 나가면 가장 오래된 길드원이 맡습니다
- 계정은 없습니다. 들어갈 때 받은 열쇠를 세이브에 두고, 서버는 그 해시만 갖습니다

## 박스 · 도감 · 성장

셋을 구분합니다.

| | |
|---|---|

바탕화면에 누구를 띄우든 **성장에는 영향이 없습니다.** 토큰은 언제나 키우는 아이에게 갑니다.

### 진화 단계

실제 사용량(하루 5천만~1억)에 맞춰 잡았습니다.

| 단계 | 누적 토큰 | 레벨 |
|---|---|---|
| 알 | 0 | — |
| 부화 | 5M | 1 |
| 1차 진화 | 80M | 6 |
| 최종 진화 | 400M | 27 |
| 마스터 (이로치) | 1.5B | 100 |

기본값이면 하루 1억 기준 마스터까지 2~3주입니다.
설정의 **성장 속도**로 조절합니다 — 높일수록 빨리 자랍니다.

난이도는 임계값을 고치지 않고 **성장량에 곱해서** 적용합니다.
그래야 되돌렸을 때 값이 정확히 복원됩니다.

### 변하지않는돌

상점에서 사서(🍬3) **박스 › 상세 › 지닌 물건** 에서 지니게 합니다. 지닌 아이는 원작처럼
**모습은 그대로 두고 레벨·기술만 계속 오릅니다.** 빼면 돌은 가방으로 돌아오고, 그동안 쌓인
만큼 바로 진화합니다.

- 막는 건 다른 종으로 바뀌는 진화뿐입니다. 2단 라인의 1차→최종, 마스터(이로치), 알 부화는 막지 않습니다
- 교환으로 보내면 돌도 함께 가고, 지닌 채 받으면 교환 진화를 하지 않습니다

## 한도 표시

로그에는 "얼마나 썼나"만 있고 **"한도가 얼마인가"는 없습니다.**
그래서 퍼센트는 한도를 아는 경우에만 그립니다. 모르는 값으로 %를 지어내지 않습니다.

- **Codex 주간** — opencodex가 캐시해 둔 공식 값을 읽습니다. 자동입니다
- **그 외** — 설정 › **한도 맞추기** 에서 한 번 맞춰 주면 됩니다

### 맞추는 법

토큰 단위 한도는 어디에도 공개돼 있지 않습니다. 대신 **지금 몇 %인지**만 알려주면
한도를 역산합니다 — 쓴 양은 이미 정확히 재고 있으니까요.

```
한도 = 쓴 양 ÷ (퍼센트 / 100)
```

1. 터미널에서 `claude` 를 띄우고 `/usage` 를 칩니다
2. 설정 › 한도 맞추기에 **주간 리셋 요일·시각**을 먼저 넣습니다
3. 5시간·주간 퍼센트를 넣고 `맞추기`

한도는 요금제가 바뀌기 전엔 상수라 **한 번만 하면 됩니다.**

> **주간 리셋 요일을 꼭 넣으세요.** Claude 주간 한도는 정해진 요일·시각에
> 리셋되는데, 이걸 모르면 "최근 7일 롤링"으로 세게 됩니다. 둘은 다른 값이라
> 리셋 직후에 맞추면 한도가 수십 배 틀리게 역산됩니다.

## macOS 원본과 다른 점

| | macOS | Windows |
|---|---|---|
| 숫자 표시 | 메뉴바에 **글자로** | 트레이는 아이콘만 → **툴팁 + 팝오버** |
| 창 | NSStatusItem popover | frameless BrowserWindow |
| 펫 드래그 | AppKit | `app-region: drag`를 쓰면 클릭 이벤트가 안 와서 **직접 구현** |
| Claude 한도 % | Keychain 토큰으로 API 호출 | **미지원** — 아래 참고 |

Windows 트레이는 텍스트 라벨을 지원하지 않습니다. 이 앱의 가장 큰 설계 차이입니다.

원본은 Keychain에서 토큰을 꺼내 공식 한도를 받아옵니다. Windows에는 Keychain이 없고
Claude Code가 토큰을 자격 증명 관리자에 두기 때문에 같은 방식을 쓸 수 없습니다.
**다른 도구의 인증 정보를 읽는 코드를 넣지 않기로 했습니다** — 대신 위의 퍼센트 보정을 씁니다.

도감 번호와 한국어 이름을 손으로 적으면 반드시 틀립니다. 출처에서 받아 생성하고,
결과물을 커밋해서 실행 시 네트워크를 타지 않게 합니다.

### 토큰을 어떻게 세나

`input + output + cache_creation + cache_read` 를 전부 더합니다.
청구 기준이 아니라 "얼마나 굴렸나"가 관심사이기 때문입니다.
캐시를 빼면 하루 수치가 1/10로 줄어 게임이 성립하지 않았습니다.

Claude는 **한 응답이 여러 레코드로 쪼개져 같은 usage를 반복해서 들고 옵니다.**
`requestId`로 중복을 걸러야 합니다 — 안 그러면 1.8배 부풀려집니다.
Codex의 `total_token_usage`는 세션을 넘어 누적되므로 절대 합산하면 안 됩니다.
